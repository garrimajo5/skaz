# СКАЗ

Интерактивный лист персонажа и дневник приключения для **D&D 5e 2014**. Основной сценарий — игрок с планшетом на очной сессии с интернетом.

## Текущее состояние

Кликабельный клиентский UX-прототип. **Полярис** — основная тема. Уголь и Атлас сохранены как поддерживаемые варианты; выбор сохраняется в браузере. При первом запуске и сбросе демонстрации выбирается Полярис.

Работают лист персонажа, поиск восьми демо-заклинаний, расход ячеек, здоровье, вдохновение, отдых, журнал, подтверждение событий, задания и заметки на схематической карте. Данные демонстрационные, хранятся только в браузере.

**Сервер, полная база материалов, авторизация и распознавание речи пока не реализованы.** Журнал показывает заранее подготовленные реплики. Ссылки на dnd.su не являются интеграцией.

## Запуск

Нужен Node.js 22 или новее. Внешних пакетов нет, установка зависимостей не требуется.

```sh
npm run dev
```

Открой http://127.0.0.1:4173. Локальный сервер обслуживает только клиент, это не сервер приложения.

Если Node установлен без npm, запуск: `node scripts/dev.mjs`, сборка: `node scripts/build.mjs`.

```sh
npm run check
npm run build
```

Сборка создаёт статическую версию в `dist/` и автономный `dist/skaz.html`, который можно открыть в браузере без запуска сервера. Шрифты загружаются из Google Fonts; при недоступности используются системные.

## Структура

- `client/` — интерфейс и демонстрационное состояние.
- `server/` — границы будущего серверного приложения.
- `docs/product-concept.md` — продуктовый концепт, архитектура и этапы MVP.
- `docs/design/` — концепт-арт и правила темизации.
- `scripts/` — локальный запуск и сборка без зависимостей.

## Следующие этапы

1. Доработать UX Поляриса на реальном планшете, сохраняя совместимость тем.
2. Реализовать серверное хранение персонажей, кампаний, сессий, заданий и событий.
3. Подключить каталог 2014 с указанием источника и версии каждого материала.
4. Проверить извлечение сюжетных событий на короткой записи, затем на полной сессии.

Перед массовым импортом материалов нужно определить доступный способ подключения и условия использования источника. Секреты и аудиозаписи в репозиторий не добавляются.
