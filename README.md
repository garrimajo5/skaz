# СКАЗ

Интерактивный лист персонажа и дневник приключения для **D&D 5e 2014**. Основной сценарий — игрок с планшетом на очной сессии с интернетом.

## Текущее состояние

Локальное клиент-серверное приложение **0.2**. Node.js обслуживает интерфейс и API, SQLite хранит прогресс. **Полярис** — основная тема. Уголь и Атлас сохранены; выбор темы запоминается отдельно в каждом браузере.

Работают сохранение ресурсов персонажа, кампании и сессии с постоянными ID, архив журнала, инвентарь с чтением сохранённых карточек и личный список заклинаний из серверного каталога. Задания кампании показываются сразу с поиском, фильтром и быстрыми отметками этапов. На карте можно создавать места, оставлять сведения, отмечать посещение и задавать положение на условной схеме.

В журнале есть **ручные предложения событий**: введи фрагмент разговора, говорящего, время и цель (сюжет или личная заметка), проверь и исправь запись, затем подтверди либо пропусти. Исходная фраза сохраняется отдельно. Принятие не меняет игровые ресурсы и не повторяется при повторной доставке команды. Это подготовка распознавания; запись звука и AI ещё не подключены. Предложения доступны в текущей сессии; перед её завершением нужно проверить ожидающие события. В «Сессиях» доступен архив исходных событий с поиском и фильтром решений, только для чтения.

В «Кампаниях» можно создать дополнительного персонажа из демо-шаблона и выбрать героя. Его ресурсы, личные заметки, инвентарь и заклинания хранятся отдельно; журнал сессии, задания и карта общие. Имя выбранного героя видно в заголовке. JSON v7 переносит только выбранного персонажа; полная копия всей партии — SQLite backup.

Есть статус сохранения, защита от конфликтов вкладок и повторных запросов, сохраняемая очередь при сбое, история изменений, экспорт/импорт и резервные копии SQLite. Форма «Событие из текста» сохраняет локальный черновик до отправки и восстанавливает его после перезагрузки. Формы задания и места также сохраняют локальный ввод, этапы и положение; восстановление ограничено той же вкладкой, героем, сессией и версией игры. Старые версии доступны для скачивания в «Несохранённых черновиках». Другие формы до нажатия сохранения не являются черновиками. Демо-шаблон барда 5 уровня, восемь демонстрационных заклинаний с расходом ячеек и примерные механики листа остаются ограничениями. Собственные классы, индивидуальные учётные записи и полная база материалов ещё не готовы. Закрытый сервер для владельца доступен через HTTPS и общий пароль на входе; выбор кампании и героя независим для каждой вкладки, индивидуальный вход и роли реализованы экспериментально, включение на VPS ожидает полной браузерной проверки. Экспериментальный интерфейс владельца управляет составом и явным доступом к каждому листу с подтверждением; проверка готовности базы к миграции выполняется отдельной командой только для чтения (docs/access-control.md). Полярис, Уголь и Атлас поддерживаются.

Перед обновлением останови предыдущий сервер и сделай резервную копию старой версией. [Совместимость и сущности](docs/entities.md).

## Запуск

Нужен Node.js 24 или новее. Внешних пакетов для запуска нет, установка зависимостей не требуется. Полный набор тестов HTTPS использует OpenSSL: на Windows автоматически ищется версия из Git, на Linux — openssl в PATH; другой путь можно задать SKAZ_OPENSSL. Одноразовый сертификат создаётся в системной временной папке, доверие устройства не меняется.

```sh
npm run dev
```

Открой http://127.0.0.1:4173. При первом запуске автоматически создаётся `data/skaz.sqlite`. По умолчанию приложение доступно только с этого компьютера. Закрытое размещение за HTTPS-прокси описано в [развёртывании](docs/deployment.md).

Если Node установлен без npm, запуск: `node scripts/dev.mjs`, сборка: `node scripts/build.mjs`, тесты: `node --test --test-isolation=none tests/*.test.mjs`.

```sh
npm run check
npm test
npm run build
npm run backup
```

Сборка создаёт клиент в `dist/` и автономный `dist/skaz.html`. HTML-файл при открытии без сервера остаётся демонстрацией с браузерным сохранением; для настоящей базы используй HTTP-адрес локального приложения. Шрифты загружаются из Google Fonts; при недоступности используются системные.

## Резервные копии и перенос

«Данные и настройки → Скачать прогресс» экспортирует JSON. Текущий формат v7 переносит активную игру в новую кампанию: ресурсы, текущий журнал, личные заметки, инвентарь с текущими зарядами, заклинания с источниками, задания, места и предложения событий с принятыми решениями. Первоначальные ID сохраняются как происхождение; локальные ID создаются заново. Архивы сессий и история изменений не входят. Импорт v1–v6 совместим, но у старых форматов меньше данных; v1 заменяет только текущий агрегат прогресса. Предпросмотр объясняет состав до записи. `node scripts/backup.mjs` создаёт полную копию базы с историей в `backups/`, даже когда приложение работает. Для восстановления SQLite останови сервер и запусти его с `SKAZ_DB`, указывающим на копию; не заменяй файл работающей базы. Копии стоит хранить и на другом диске.

`data/`, `backups/` и SQLite-файлы исключены из Git. По умолчанию проверяется не более 512 КиБ на сохранение. Лимиты первой версии: 2000 записей журнала, 2000 личных заметок и 1000 заметок карты; общий лимит размера может наступить раньше.

## Структура

- `client/` — интерфейс, темы и транспорт сохранений.
- `server/` — HTTP API, валидация, SQLite и история изменений.
- `tests/` — проверки сохранения, конфликтов, повторных запросов, резервных копий и HTTP API.
- `docs/local-api.md` — контракт API и границы текущего хранения.
- `docs/hosting.md` — требования к будущему хостингу и распознаванию.
- `docs/product-concept.md` — продуктовый концепт, архитектура и этапы MVP.
- `docs/design/` — концепт-арт и правила темизации.
- `scripts/` — локальный запуск и сборка без зависимостей.

## Каталог и ограничения

Серверный [каталог](docs/catalog.md) подключён к «Справочнику»: поиск RU/EN по названиям или описаниям с фрагментом совпадения, категории, уровень, школа, ритуал и концентрация заклинания, опасность, тип и размер существа, редкость, тип и настройка предмета, страницы и сведения об источнике. Проверенную подборку можно установить кнопкой в справочнике, с предпросмотром и обновлением только точно известных прежних версий; личные правки защищены. Поддерживается личный JSON-импорт. Есть небольшая проверенная подборка пятнадцати состояний, тридцати семи правил, 319 заклинаний, сорока девяти магических предметов, пятидесяти трёх существ и одного артефакта SRD 5.1 (CC BY 4.0), с русским кратким изложением и явным учётом пропусков. Всего в подборке 475 материалов (474 CC BY 4.0 и одна справочная ссылка). Перечень 319 названий SRD показывает готовность и страницы источника; готовы краткие изложения всех 319 заклинаний уровней 0–9 SRD. Карточки содержат краткие изложения; ограничения и замеченная опечатка первоисточника отмечены в манифестах. В списке справочника видны основные характеристики; переход между страницами доступен сверху и снизу. Длинные карточки имеют закреплённые переходы к описанию, связям и источнику. В личной книге доступны фильтры ритуала и концентрации. Это не полная база D&D. Условия массового импорта dnd.su не установлены; справочные ссылки не являются интеграцией.

Инвентарь поддерживает добавление из каталога, поиск RU/EN, фильтр требования настройки, страницы по десять записей, количество, списание и отмену последней операции до следующего изменения игры. Из сохранённого предмета можно открыть актуальные связанные правила и вернуться без изменения его карточки. Максимум зарядов и восстановление — справочные поля; текущий остаток каждого экземпляра можно задать, потратить и восстановить вручную; настройка пока не автоматизирована. Эффекты предметов не применяются автоматически. Личная книга на основном экране магии поддерживает поиск RU/EN, фильтры уровня и отметки, страницы, ручные отметки изучено/подготовлено и удаление; ограничения класса и расход ячеек для этих записей не автоматизированы. Статусы заданий и награды также меняются вручную. Карта пока без фонового изображения и измерения расстояний.

## Следующие этапы

Актуальная очередь, критерии готовности и проверки: [план разработки](docs/DEVELOPMENT_PLAN.md). Ближайшее продолжение — расширение проверяемого каталога и его применения к листу. Доступ с настоящего планшета и шестичасовой сценарий требуют отдельной проверки. Требования к будущему серверу описаны в [hosting.md](docs/hosting.md). Микрофон и платные AI-вызовы требуют отдельного решения.

Личные подборки можно добавлять через «Справочник → Личный импорт»: JSON-файл, предпросмотр, явное подтверждение. В окне есть пример формата. Поддерживается только 2014; конфликтующие материалы не заменяются, повтор не создаёт дубли. Ограничение веб-импорта — 512 КиБ вместе с запросом.

При возвращении во вкладку приложение проверяет версию игры. Если другое окно изменило её, текущий экран и незавершённая форма остаются на месте; дальнейшие изменения заблокированы до явного обновления. Кнопка ↻ позволяет проверить вручную. Форма ручного события сохраняет локальный черновик до подтверждённой отправки; остальные незавершённые формы перед обновлением следует скопировать. Это предупреждение об устаревших данных, не совместное редактирование в реальном времени.


## Заряды предметов

В инвентаре кнопка «Заряды» открывает ручной учёт каждого экземпляра. Новый предмет имеет неизвестный остаток, а не полный запас. Можно задать остаток, потратить или восстановить заряды; предварительный результат виден до записи. Ноль не удаляет предмет, автоматических бросков и эффектов нет. При списании количества удаляются последние экземпляры списка; операция отменяется до следующего изменения игры. JSON v7 сохраняет индивидуальные остатки, старые форматы при наличии зарядов отказывают вместо потери данных.

Серверная [основа личного доступа](docs/access-control.md) содержит членство, разрешения на героев, проверку чтения/записи/повторов и административную команду с резервной копией. Это экспериментальная часть: индивидуальный вход и интерфейс участников ещё не подключены, VPS остаётся с общим паролем.
