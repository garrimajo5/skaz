# Протокол проверки правил каталога — 15.11.2026

## Офлайн-воспроизведение

Node.js >=24, без сервера, браузера и данных пользователей.
На исходном состоянии этого audit PR команда воспроизводит сохранённый
результат побайтово; после исправления карточек новый отчёт закономерно
отличается. Исходный отчёт исторический, его не перезаписывать.

```sh
node scripts/dndsu-rule-fields.mjs audit catalog/dndsu-rule-index-2026-11-15.json data/current-rule-audit.json
node --test --test-isolation=none tests/dndsu-rule-fields.test.mjs tests/dndsu-name-audit.test.mjs
```

Перед первой командой создать `data/`, если каталога нет.
JSON содержит SHA снимка и полного набора исходных карточек.
Источник baseline — `01e5717`; чтобы повторить именно baseline после
будущих исправлений, использовать первоначальный коммит audit PR, а не
текущую ветку с изменёнными карточками.

## Повторное получение источников

```sh
node scripts/fetch-dndsu-indexes.mjs data/dndsu-refresh
node scripts/dndsu-rule-fields.mjs snapshot data/dndsu-refresh data/refreshed-rule-index.json
node scripts/dndsu-rule-fields.mjs audit data/refreshed-rule-index.json data/refreshed-rule-audit.json
node scripts/fetch-dndsu-rule-samples.mjs data/dndsu-refresh/samples
node scripts/verify-dndsu-rule-sources.mjs data/dndsu-refresh/samples
```

Fetch ограничен тремя индексами и 13 явно перечисленными статьями.
HTTP ошибки, редиректы, неверный тип, размер, неподдержанный формат,
пропавшие границы статьи/поля, дубли и устаревшие связи дают ошибку.
Чужой JavaScript не выполняется; комментарии и навигация не служат
доказательством правила. У статьи фиксируются полный SHA и SHA очищенного
articleBody. При обновлении рекламы полный SHA может меняться; проверка
статьи требует прежний articleBody SHA и все объявленные sourcePatterns.
При изменении статьи нужна новая ручная сверка, не автоматическое принятие.

## Фактические результаты

- 13/13 Node-тестов: 9 новых и 4 существующих теста парсера имён.
- 13/13 исходных статей и 25/25 исходных наборов якорей подтверждены
  локальными сырыми ответами и закреплёнными хешами.
- 1856/1856 индексных значений совпадают; 19/25 условий присутствуют,
  шесть имеют явный открытый статус.
- Проверены мутации: потеря поля, неверный уровень/компоненты, пропавшая
  карточка, новая несопоставленная карточка, дубликаты, пустой текст,
  неизвестная кодировка, подмена правил комментариями.
- `git diff --check` без ошибок.

Первый запуск стандартного `node --test` в ограниченной среде получил
`spawn EPERM`, до выполнения тестов. Успешный прогон выполнен с
`--test-isolation=none`; это не замаскированная ошибка проверки правил.
Сборка аудиторских файлов отдельно не нужна: они не входят в runtime.
Сборка и проверки исправлений данных выполняются в независимом PR.
