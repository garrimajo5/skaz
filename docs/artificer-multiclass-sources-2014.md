# Изобретатель 2014 в мультиклассе

Эта сверка разделяет доступ к заклинаниям класса, количество обычных подготовленных и общие ячейки. Она служит входом для [#82](https://github.com/garrimajo5/skaz/issues/82) и проверки источников [#77](https://github.com/garrimajo5/skaz/issues/77).

## Что подтверждают открытые источники

| Источник | Подтверждённая область |
| --- | --- |
| [Basic Rules 2014, Spellcasting](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/customization-options#Spellcasting) и [SRD 5.1, PDF 57–58](https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf#page=57) | Заклинания выбираются и подготавливаются по уровню каждого класса. Высокий круг общей ячейки доступен для сотворения подходящего заклинания низшего круга. Условия класса, фокус и заклинательная характеристика сохраняются. Если особенность Spellcasting есть у одного класса, берётся его таблица. Магия договора имеет отдельный источник и допускает использование ячеек для заклинаний другого источника по общему правилу. |
| [Официальное руководство Tasha для Adventurers League, PDF 1](https://media.wizards.com/2020/dnd/downloads/dnd_tcoe_alguidance.pdf#page=1) | Указано, какие списки относятся к подготовке через Spellcasting изобретателя и через Spellcasting другого класса в этой организованной кампании. Ограничение PH+1 относится к указанному формату AL. Для СКАЗ это свидетельство о границе источников подготовки. |
| [Artificer 101: Armorer, Spells](https://www.dndbeyond.com/posts/912-artificer-101-armorer-from-tashas-cauldron-of) и [Artificer 101: Alchemist, Spells](https://www.dndbeyond.com/posts/908-artificer-101-alchemist-from-tashas-cauldron-of) | Редакционные статьи одного автора дают одинаковую формулу подготовки: модификатор Интеллекта + половина уровня изобретателя с округлением вниз, минимум одно. Это вспомогательное свидетельство, как указано в [#82](https://github.com/garrimajo5/skaz/issues/82#issuecomment-7115574783). |
| [Tasha, Artificer → Class Features](https://www.dndbeyond.com/sources/dnd/tcoe/artificer#ClassFeatures) и [Eberron, Character Creation](https://www.dndbeyond.com/sources/dnd/erftlw/character-creation) | Открытое оглавление Tasha содержит ссылки на класс и подклассы. При переходе обе книги направили в магазин. Точный раздел опубликованного класса с исключением для общих ячеек и полный текст о всегда подготовленных заклинаниях не получены. |

Проверен PDF Adventurers League на одной странице. SHA-256 `6ab6ee27f666c1acecc72621031244cecc85b0b2a1c710670e06ba9df5a9955f`. Граница раздела Spellcasting заканчивается перед Artificer Infusions. Сам PDF остаётся вне Git.

## Контрольные сценарии для следующего шага #82

| Вымышленный вход | Ожидаемый результат проверки |
| --- | --- |
| Следопыт 3 / волшебник 3 | Подтверждённая формула 2014 даёт эффективный уровень 4 и 4/3 общие ячейки. Округление вверх по ошибке дало бы уровень 5 и добавило бы ячейки 3-го круга. |
| Изобретатель 3 / волшебник 5, модификатор Интеллекта +3 | При сверке гипотезы об округлении вклада изобретателя вверх эффективный уровень равен 7, общие ячейки 4/3/3/1. Контрольный ошибочный вариант с округлением вниз даёт уровень 6 и 4/3/3. В обоих вариантах волшебник 5 получает доступ к обычным заклинаниям своего класса до 3-го круга. Число обычных подготовленных у изобретателя в редакционном примере равно четырём; общая ячейка и подготовка проверяются отдельно. |
| Волшебник 3 / колдун 2 | Ячейки Spellcasting и Pact Magic принадлежат разным пулам. Правило об использовании ячеек другого пула применяется только к уже известным или подготовленным заклинаниям. |

Вторая строка остаётся кандидатом для приёмки после сверки опубликованного абзаца `Multiclassing and the Artificer → Spell Slots`. Для всегда подготовленных нужны точный текст и таблица выбранного подкласса с публикацией и версией. До этого расчёт изобретателя не входит в принимаемый объём. При будущем расчёте превышение игрового лимита даёт предупреждение и сохраняет подтверждённую ручную правку. #82 остаётся Backlog по указанным зависимостям.
