## Что устанавливает первая страница

Это сборник официальных разъяснений правил исходной пятой редакции, а не ещё один список заклинаний/монстров/предметов. Введение ссылается на три основные книги, впервые вышедшие в2014. На проверенном PDF указаны версия2.7 и copyright2021; путьURLс2020 не является годом этой версии. Имеются отдельные разделы справочных ссылок, официальных разъяснений и собранных ответов. Первая страница отрендерена Poppler100dpi и полностью просмотрена автором.

Разъяснения сохраняют решение мастера; публичные заявления сотрудников/соцсети не становятся официальными разъяснениями автоматически. Это поддерживает согласованный принцип предупреждений и ручного пути, а не даёт приложению право запрещать личные отклонения. Полный набор ответов и их отдельные условия здесь не проверены.

## Отдельные границы

- Provider53/SageAdviceCompendium2014 связан с первичным PDF как кандидатом справочного источника. Числовой dnd.su sourceId не придуман, canonicalSourceId=null, автоматической атрибуции нет.
- Наличие этого PDF не доказывает, что текущий цифровой текст библиотечной страницы полностью совпадает сv2.7. Сохраняются точные источник/версия и неизвестное равенство текста.
- Указание личного печатного использования не принимается за право публикации текста/перевода в общем каталоге. Статус использования остаётся not-established.
- Строка15-остатка пока не удаляется: установление вида документа не принимает весь состав, единицы вопросов/версии/права или знаменатель. Полные ответы относятся к соответствующей M4-сверке после принятого реестра.

## Воспроизведение

```sh
python scripts/audit-sage-advice-boundary-2014.py <capture-folder>
python -m unittest discover -s tests -p test_sage_advice_boundary_2014.py
```

Папка содержит sage-advice.pdf и capture.json. До чтения проверяются точныеURL/status/bytes/SHA; после — версия/год/23страницы и заголовки первой страницы. Входные библиотечные JSON закреплены SHA, генератор отдельно.6Python/4общихSHA автора прошли. Независимое content/QA/game-design ревью — отдельно; это не утверждение полной проверки23страниц. Runtime/профили/браузер/Android/VPS не менялись, выпуск неприменим, #77/M0 открыты.

Рефлексия content: каталог источников содержит справочные разъяснения и выдержки, которые нельзя считать новыми правилами-статблоками. Предложение планировщику — прежде единицы/вид документа, затем подсчёт содержания. Польза — не завышать знаменатель, затраты — адресная первая страница, риск — спутать библиографическое свидетельство с проверкой всего текста, что явно исключено.
