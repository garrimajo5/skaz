Можно принять наблюдаемое переиспользование цифровой записи между двумя legacy book filters и отличие MotM-записи. Нельзя выводить из этого равенство физических первых изданий, точную errata, право перевода или удалять source129из вторичной MotM-карточки. Ненахождение modern ID в этих выбранных legacy-фильтрах не является исчерпывающей проверкой всех публикаций. Старые scope, source plaques, цифровые кандидаты и D03-reference report не меняются.
