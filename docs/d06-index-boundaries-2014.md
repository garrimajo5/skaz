# D06 · границы индексов SKT, IMR и Fiendish Folio

Сверка для [#77](https://github.com/garrimajo5/skaz/issues/77) сохраняет ID и принадлежность карточек к источникам. Статусы полного текста, канонической связи и использования материалов остаются открытыми.

## Storm King’s Thunder

В цифровой выдаче 105 карточек. У 85 указан SKT, у 20 указан Monster Manual 2014. Последние сохранены со ссылками на исходные наблюдения Monster Manual. Четыре карточки Yuan-ti Malison различаются по URL.

Из 94 наблюдений dnd.su по SKT для 25 пока нет кандидата по имени. Среди карточек издателя такой кандидат отсутствует у 16. В отчёте сохранены 3 изученные группы вариантов, 6 цифровых меток вариантов великанов, 4 строки с пустым CR, 1 заголовок приложения и 2 строки, видимые только в индексе.

Cloud Giant Child имеет CR 0 и размер Medium. Отдельная карточка Young Cloud Giant имеет CR 5 и размер Huge, а её имя совпадает с наблюдением 7728. Оснований объединять две карточки по общему имени великана нет. Пустое значение CR остаётся неизвестным. [Наблюдение Young Cloud Giant](https://dnd.su/bestiary/7728-young-cloud-giant/).

Оглавление подтверждает расположение Hulking Crab, New Giant Options, Tribal Spells и Appendix D. При прямой проверке три карточки без CR перенаправили в магазин, Vaasha завершилась тайм-аутом. Состав четырёх именных карточек описан ниже. Остальные связи вариантов и точный список 22/24 ещё проверяются. Список относится к шаману и не добавляет отдельную единицу существа, его состав нужен в M4. [Оглавление SKT](https://www.dndbeyond.com/sources/dnd/skt), [официальные исправления](https://www.dndbeyond.com/sources/dnd/sae/storm-kings-thunder).

### Именные карточки штормовых великанов

На печатной странице 256 (страница 10 PDF) находится один общий блок Storm Giant и четыре именные карточки для главы 12. Издатель предлагает выдать каждому игроку копию общего блока вместе с одной именной карточкой. Nimir, Orlekto, Shaldoor и Vaasha добавляют индивидуальные навыки и сведения для отыгрыша. Все четыре строки остаются в цифровом индексе со своими URL и пустым CR. В приложении D это четыре именных дополнения к одному блоку. Число канонических единиц и эквивалентность блоку Monster Manual 2014 подлежат отдельному решению. [Официальное приложение D](https://media.wizards.com/2016/dnd/downloads/SKT_AppD.pdf#page=10).

[Машиночитаемая сверка](../catalog/skt-appendix-d-npc-composition-2014.json) хранит страницы, SHA-256 исходника и четыре связи. Скачанный PDF весит 1 497 598 байт. Для воспроизведения скачать PDF по ссылке, сверить SHA с реестром и открыть страницу 10. Разрешение в полях страницы касается копирования для домашней игры. Основание для публикации текста в СКАЗ остаётся открытым.

### Дополнительные действия великанов

На открытой печатной странице 246 есть отдельные заголовки Frost, Hill, Stone и Storm Giants. Под ними описаны соответственно одно, одно, два и одно дополнительных действия для взрослых великанов. Это подтверждает форму четырёх вариантов в приложении C. Их цифровые карточки сохраняются по собственным URL и CR. Совпадение полного содержимого с цифровыми карточками остаётся открытым. Для Fire и Cloud Giant нужны соседние страницы: у первых двух фрагментов на странице 246 отсутствует заголовок родителя. [Официальная страница приложения C](https://media.wizards.com/2016/dnd/downloads/SKT_GiantOptions.pdf).

[Реестр вариантов](../catalog/skt-appendix-c-giant-options-2014.json) связывает все шесть цифровых строк с четырьмя подтверждёнными заголовками и двумя открытыми. Для воспроизведения скачать одностраничный PDF размером 728 068 байт, сверить SHA-256 и проверить заголовки страницы 246. Текст действий и иллюстрация остаются в источнике. Право на публикацию текста и число канонических единиц требуют отдельных решений.

## Infernal Machine Rebuild и Fiendish Folio

Индекс IMR содержит 56 карточек. У 26 указан IMR, из них у пяти есть наблюдения исходного источника IMR. У 30 карточек указаны другие книги. Boggle и Redcap имеют отдельные цифровые версии. Число 26 на странице издателя относится к доступности в Encounter Builder. Ссылка на приложение B ведёт в магазин при публичной проверке. [Оглавление IMR](https://www.dndbeyond.com/sources/dnd/imr), [страница IMR](https://marketplace.dndbeyond.com/adventures/SRC-00056).

В двух индексах совпадает ровно один URL, Eye of Fear and Flame. Цифровая карточка помечена как IMR, исходное наблюдение остаётся в источнике Folio 206, печатная единица сохранена. Для Folio отдельно учтены 18 строк печатного оглавления, исторические 17 из описания цифрового продукта, 18 карточек текущего фильтра и 17 карточек с подписью Folio. Печатная эквивалентность Eye и причина исторического расхождения остаются без доказательства. [Цифровая карточка](https://www.dndbeyond.com/monsters/581278-eye-of-fear-and-flame), [разъяснение сотрудника издателя](https://www.dndbeyond.com/forums/d-d-beyond-general/release-issues-support/53208-mordenkainens-fiendish-folio-volume-1-bugs-and#c8).

Needlefolk / Needle Spawn остаётся кандидатом. CR 1/2 совпадает, публичная ссылка на карточку перенаправляет к товару. Для решения нужна доступная страница соответствующей версии или прямое подтверждение издателя. [Цифровая карточка Needle Spawn](https://www.dndbeyond.com/monsters/589001-needle-spawn).

## Воспроизведение

- [SKT](../catalog/skt-index-residual-2014.json) собирается командой `node scripts/review-skt-index-residual-2014.mjs`.
- [IMR и Folio](../catalog/imr-folio-index-boundary-2014.json) собирается командой `node scripts/review-imr-folio-index-boundary-2014.mjs`.
- У обоих генераторов `--verify-toc <saved HTML>` проверяет SHA-256 сохранённого оглавления и ожидаемые ссылки. Сырые страницы хранятся отдельно от репозитория.
- `node --test tests/skt-index-residual.test.mjs tests/skt-appendix-d-npc-composition.test.mjs tests/skt-appendix-c-giant-options.test.mjs tests/imr-folio-index-boundary.test.mjs` проверяет разбиение по источникам, сохранение исходных ID и запрет продвижения кандидатов.

Для следующих решений D06 нужны соседние страницы приложения C для Cloud и Fire Giant, главы с остальными вариантами SKT и свидетельство связи Needlefolk / Needle Spawn. Планировщик может независимо сверять спорные единицы и права D07. #77 и этап M0 остаются открытыми.

Рефлексия. Соединение по точному публичному URL и две отдельные выборки строк без совпадений сократили ручную сверку. При следующем пересмотре стоит сохранять ссылку на раздел и причину отсутствия полного текста вместе с карточкой. Это ускорит повторную проверку без потери происхождения.
