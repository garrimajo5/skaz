# Каталог D&D 2014

## Текущее состояние — 20 октября 2026

Подборка содержит 543 материала: 15 состояний, 37 правил, 319 заклинаний, 121 существо, 49 предметов, 1 артефакт SRD 5.1 (542 CC BY 4.0) и одну справочную ссылку. Это ограниченные краткие изложения, не полная база D&D. Старые разделы ниже сохраняют историю наполнения; их числа относятся к соответствующим этапам.

Каталог хранится отдельно от прогресса, устанавливается по кнопке с предпросмотром, поддерживает личный JSON-импорт, поиск RU/EN, категории, уровень/школу/ритуал/концентрацию заклинания, диапазон опасности и редкость предмета. Карточки показывают структурированные характеристики и происхождение. Личный список заклинаний доступен на основном экране магии с поиском, фильтрами, страницами и ручными отметками; демонстрация свёрнута отдельно. Предметы и артефакты добавляются в инвентарь. Автоматического применения правил каталога нет. Полная SQLite-копия включает каталог; экспорт v9 переносит зависимости выбранного персонажа, а не весь каталог.

Добавлены 98 материалов без изменения прежних 176: 42 заклинания третьего уровня, 31 четвёртого, 6 пятого (Commune, Greater Restoration, Mass Cure Wounds, Raise Dead, Telepathic Bond, Teleportation Circle), Riding Horse, 8 базовых и 10 боевых правил. Пакеты `srd51-level-three`, `srd51-level-four`, `srd51-level-five-support`, `srd51-summoned-forms`, `srd51-core-rules`, `srd51-combat-rules` имеют отдельные JSON и манифесты охвата с источником, страницами, версией, SHA-256 и ограничениями.

Готовы 319/319 кратких изложений: все заголовки уровней 0–9 закреплённого SRD 5.1. Полнота всех книг не заявляется. Zombie уже присутствовал в старом пакете и повторно не добавлен. Phantom Steed ссылается на базовую форму Riding Horse; скорость эффекта 100 футов не заменяет исходные 60 футов зверя.

Механики фильтруются по разделам: состояния, накладывание заклинаний, бой, отдых. Связи Ready → Concentration → Incapacitated доступны для чтения. Хиты, концентрация, отдых, броски и действия автоматически не меняются. Tiny Hut содержит явное замечание о неоднозначном числе существ в тексте источника; решение остаётся за мастером.

Для проверки полного текста используется `python scripts/extract-srd-spell-bodies.py data/srd51-source.pdf data/spell-bodies-review.json`. Скрипт узнаёт заголовки по закреплённому индексу 319 имён, уровню, школе и строке Casting Time, проверяет уникальность и страницу; не обрывает текст на похожем на заголовок пункте списка. Вывод — локальный материал для ручной сверки, не импортный пакет; существующий файл не перезаписывается. Два извлечения совпали побайтово. Проверка полей всех 319 заклинаний успешна, но не заменяет ручную проверку изложений и условий реакций.

### Повторяемая сверка источника

Нужны Python с pypdf, Node.js и локальный официальный PDF. Скрипты проверяют SHA-256 до чтения; ничего не скачивают и не меняют базу.

```sh
python scripts/audit-srd-spell-cards.py data/srd51-source.pdf
python scripts/audit-srd-monsters.py data/srd51-source.pdf
python scripts/audit-srd-items.py data/srd51-source.pdf
python scripts/audit-srd-travel.py data/srd51-source.pdf
python -m unittest discover -s tests -p "test_srd*.py"
```

Первая команда сравнивает компоненты, дистанцию, длительность, концентрацию, ритуал и тип/время действия всех 319 подготовленных заклинаний. Формулировки условий реакций и русские изложения требуют отдельной сверки. Вторая сравнивает размер, тип, КД, хиты, скорости, шесть характеристик, опасность и опыт всех 32 существ; атаки, чувства и особенности остаются предметом ручной проверки. Третья проверяет метаданные всех 49 предметов, четыре формулы лечения, максимумы зарядов палочек и границы таблицы Wonder. Четвёртая сравнивает девять расстояний таблицы темпа путешествия со страницей 84, включая дневные 30/24/18 миль; она не пересчитывает день как восемь часовых значений. Неподдержанная запись в PDF даёт ошибку, а не подстановку соседнего статблока. Тесты отдельно проверяют переносы страниц, отсутствие запятой после Concentration и границы соседних записей.

## Личный импорт

Храни личные JSON в игнорируемом `data/`, не в исходниках. Команды из корня проекта:

```sh
node scripts/import-catalog.mjs data/my-catalog.json
node scripts/import-catalog.mjs data/my-catalog.json --apply
```

Первая команда проверяет пакет и сообщает число новых/совпавших записей, вторая сохраняет весь пакет атомарно. Повтор идентичного пакета ничего не дублирует. Изменённое содержимое занятого ID отклоняется; редактирование версий будет отдельным этапом. Проверка может создать пустую базу, если её ещё нет. `SKAZ_DB` задаёт другую базу.

Формат: `schemaVersion: 1`, `entries` от 1 до 1000 записей, файл до 5 МиБ. Пример справочной записи — `catalog/references.json`. Каждая запись требует стабильный ID, `ruleset: 5e-2014`, категорию mechanic/spell/monster/item/artifact, названия name.ru/name.en, source.url/title/version/usage/terms и массив связей links на существующие или импортируемые ID. Неизвестные поля отклоняются. Для категории spell доступна необязательная структура spell, описанная ниже. Для item доступна структура магического предмета, описанная ниже. Числовые характеристики остальных категорий пока не поддерживаются.

`reference-only` хранит только метаданные и ссылку, без text. `personal` допускает необязательный текст до 20000 символов для собственных или разрешённых пользователю материалов. Поле terms фиксирует заявленные условия, но само по себе не подтверждает права. Импорт не проверяет истинность характеристик или условия внешнего сайта и не обращается к URL.

GET `/api/catalog?q=...&kind=spell&limit=50&offset=0` возвращает entries/total/limit/offset; поиск по названиям, без учёта регистра RU/EN. Лимит 1–100, смещение целое ≥0. GET `/api/catalog/coverage` возвращает количество по категориям и режимам использования, complete=false, неизвестный expectedTotal=null и пробелы. Поиск пока перебирает каталог в памяти; для большой базы нужен индекс.

### Структура spell

Необязательна для совместимости с прежними пакетами. Разрешена только у kind=spell; reference-only запрещает и text, и spell. При наличии структуры все перечисленные поля обязательны:

- level: целое 0–9; school: abjuration/conjuration/divination/enchantment/evocation/illusion/necromancy/transmutation.
- castingTime и duration: непустые строки до 200 символов. Это описания, не исполняемые правила.
- range: type=self/touch/feet/sight/unlimited/special. Только для feet обязательно целое feet от 1 до 10000000 (технический предел); для остальных feet запрещено. Особые дистанции поясняются в text.
- components: непустой массив V/S/M без дублей, канонически сортируется. Материалы и стоимость описываются в text.
- concentration и ritual: строго boolean.

Неизвестные поля и неверные числа отклоняют весь пакет. Порядок компонентов не влияет на повтор импорта. Отсутствие структуры не означает отсутствие характеристик в правилах.

## Магические предметы — 19 октября 2026

`catalog/srd51-items.json`: четыре отдельных варианта Potion of Healing (страница 234, таблица) и Cloak of Protection (страница 214). Сверены с тем же официальным PDF SRD 5.1 и SHA-256, указанным выше. Формулы вариантов: 2d4+2, 4d4+4, 8d4+8, 10d4+20; редкости common, uncommon, rare, very-rare соответственно. У плаща настройка обязательна. Русские названия и краткие изложения подготовлены для СКАЗ, не являются официальным переводом. Атрибуция CC BY 4.0 и описание изменений включены в каждую запись.

```sh
node scripts/import-catalog.mjs catalog/srd51-items.json
node scripts/import-catalog.mjs catalog/srd51-items.json --apply
```

`item` необязателен для совместимости прежних пакетов. Допустим только у kind=item, запрещён для reference-only. Поля:

- type (обязательно): armor/potion/ring/rod/scroll/staff/wand/weapon/wondrous.
- rarity (обязательно): common/uncommon/rare/very-rare/legendary/varies. Артефакты не включены в эту схему.
- attunement (обязательно): boolean. Необязательный attunementRequirement — непустая строка до 200 символов, разрешена только при true.

## Установка проверенной подборки из интерфейса

## Личный импорт из интерфейса

«Справочник → Личный импорт» принимает локальный JSON-пакет схемы 1, до 1000 записей редакции 2014. В окне есть копируемый пример личной памятки; example.com в нём нужно заменить источником своего материала. Файл передаётся только локальному серверу. Полные тексты dnd.su автоматически не скачиваются.

POST `/api/catalog/import/preview` принимает строго `{bundle}`; POST `/api/catalog/import` — строго `{bundle,version}`. Оба маршрута требуют локальные Origin/Host и `X-Skaz-Client: local-v1`. Версия — SHA-256 нормализованного состава, отсортированного по ID. Изменение состава после просмотра даёт 409. Структурные ошибки — 422, конфликт ID — 409. Ответ: applied/added/unchanged/total/version/records/categories/usage/sample. Подтверждение атомарно добавляет только отсутствующие записи; совпадающие не дублируются. Повтор после потерянного ответа безопасен. Каталог не меняет ревизию игры, ресурсы, инвентарь или заклинания персонажей.

Проверено в браузере 768×1024: выбор файла → предпросмотр → подтверждение → поиск собственного материала → повторный импорт (0 новых, кнопка недоступна). Тестовые файлы и база исключены из Git; снимок docs/design/catalog-personal-import.png.
