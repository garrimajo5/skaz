# Каталог 2014: первый этап

Реализованы SQLite-хранение, поиск RU/EN, фильтр категории, отчёт охвата и локальный импорт с предварительной проверкой. Каталог отделён от прогресса; импорт не меняет персонажа. SQLite backup включает каталог, JSON экспорта прогресса — нет. Экран «Справочник» подключён к серверу: поиск по кнопке или Enter, фильтр категории, страницы по 20 записей, сведения об источнике и условиях использования. Есть состояния загрузки, ошибки с повтором и пустой выдачи. Восемь демонстрационных заклинаний остаются отдельно на экране «Магия»; добавление импортированных записей в лист пока не реализовано. Автономный HTML объясняет необходимость сервера и оставляет доступ к демо.

## Личный импорт

Храни личные JSON в игнорируемом `data/`, не в исходниках. Команды из корня проекта:

```sh
node scripts/import-catalog.mjs data/my-catalog.json
node scripts/import-catalog.mjs data/my-catalog.json --apply
```

Первая команда проверяет пакет и сообщает число новых/совпавших записей, вторая сохраняет весь пакет атомарно. Повтор идентичного пакета ничего не дублирует. Изменённое содержимое занятого ID отклоняется; редактирование версий будет отдельным этапом. Проверка может создать пустую базу, если её ещё нет. `SKAZ_DB` задаёт другую базу.

Формат: `schemaVersion: 1`, `entries` от 1 до 1000 записей, файл до 5 МиБ. Пример справочной записи — `catalog/references.json`. Каждая запись требует стабильный ID, `ruleset: 5e-2014`, категорию mechanic/spell/monster/item/artifact, названия name.ru/name.en, source.url/title/version/usage/terms и массив связей links на существующие или импортируемые ID. Неизвестные поля отклоняются. Для категории spell доступна необязательная структура spell, описанная ниже. Для item доступна структура магического предмета, описанная ниже. Числовые характеристики остальных категорий пока не поддерживаются.

`reference-only` хранит только метаданные и ссылку, без text. `personal` допускает необязательный текст до 20000 символов для собственных или разрешённых пользователю материалов. Поле terms фиксирует заявленные условия, но само по себе не подтверждает права. Импорт не проверяет истинность характеристик или условия внешнего сайта и не обращается к URL.

GET `/api/catalog?q=...&kind=spell&limit=50&offset=0` возвращает entries/total/limit/offset; поиск по названиям, без учёта регистра RU/EN. Лимит 1–100, смещение целое ≥0. GET `/api/catalog/coverage` возвращает количество по категориям и режимам использования, complete=false, неизвестный expectedTotal=null и пробелы. Поиск пока перебирает каталог в памяти; для большой базы нужен индекс.

### Структура spell

Необязательна для совместимости с прежними пакетами. Разрешена только у kind=spell; reference-only запрещает и text, и spell. При наличии структуры все перечисленные поля обязательны:

- level: целое 0–9; school: abjuration/conjuration/divination/enchantment/evocation/illusion/necromancy/transmutation.
- castingTime и duration: непустые строки до 200 символов. Это описания, не исполняемые правила.
- range: type=self/touch/feet/sight/unlimited/special. Только для feet обязательно целое feet от 1 до 10000000 (технический предел); для остальных feet запрещено. Особые дистанции поясняются в text.
- components: непустой массив V/S/M без дублей, канонически сортируется. Материалы и стоимость описываются в text.
- concentration и ritual: строго boolean.

Неизвестные поля и неверные числа отклоняют весь пакет. Порядок компонентов не влияет на повтор импорта. Отсутствие структуры не означает отсутствие характеристик в правилах.

## Магические предметы — 19 октября 2026

`catalog/srd51-items.json`: четыре отдельных варианта Potion of Healing (страница 234, таблица) и Cloak of Protection (страница 214). Сверены с тем же официальным PDF SRD 5.1 и SHA-256, указанным выше. Формулы вариантов: 2d4+2, 4d4+4, 8d4+8, 10d4+20; редкости common, uncommon, rare, very-rare соответственно. У плаща настройка обязательна. Русские названия и краткие изложения подготовлены для СКАЗ, не являются официальным переводом. Атрибуция CC BY 4.0 и описание изменений включены в каждую запись.

```sh
node scripts/import-catalog.mjs catalog/srd51-items.json
node scripts/import-catalog.mjs catalog/srd51-items.json --apply
```

`item` необязателен для совместимости прежних пакетов. Допустим только у kind=item, запрещён для reference-only. Поля:

- type (обязательно): armor/potion/ring/rod/scroll/staff/wand/weapon/wondrous.
- rarity (обязательно): common/uncommon/rare/very-rare/legendary/varies. Артефакты не включены в эту схему.
- attunement (обязательно): boolean. Необязательный attunementRequirement — непустая строка до 200 символов, разрешена только при true.
- healing (необязательно): только для potion; объект с обязательными целыми diceCount (1–100), diceSides (4/6/8/10/12/20), bonus (0–10000). Границы технические; сами по себе не подтверждают соответствие правилам.

Неизвестные поля, дробные/строковые числа, неверные категории и формулы отклоняются атомарно. Отсутствие healing означает отсутствие структурированной формулы, а не нулевое лечение. Цена, вес, заряды, полные эффекты и действия не структурированы; характеристики других предметов нельзя подставлять по догадке. healing — данные, не команда: расход предмета и восстановление хитов пока не реализованы.

Отчёт покрытия дополнен structuredItems. Проверенная подборка: 5 предметов (4 варианта зелий и 1 плащ), без заявления о полноте SRD. Текущая локальная база содержит 8 записей: 1 ссылка + 2 заклинания + 5 предметов. Импорт повторяемый и явный; новые установки загружают пакеты командами выше.


## Бестиарий — 19 октября 2026

`catalog/srd51-monsters.json` содержит Goblin (стр. 315) и Skeleton (стр. 346), сверенные с официальным PDF SRD 5.1 с указанным выше SHA-256. Русские краткие изложения подготовлены для СКАЗ. Атрибуция CC BY 4.0, страницы и сведения о переводе включены в каждую запись. Это две записи, не полный бестиарий.

```sh
node scripts/import-catalog.mjs catalog/srd51-monsters.json
node scripts/import-catalog.mjs catalog/srd51-monsters.json --apply
```

Поле monster необязательно для старых пакетов, разрешено только у kind=monster и запрещено для reference-only. При наличии все следующие поля обязательны:

- size: tiny/small/medium/large/huge/gargantuan.
- type: aberration/beast/celestial/construct/dragon/elemental/fey/fiend/giant/humanoid/monstrosity/ooze/plant/undead.
- armorClass: целое 0–100; hitPoints: целое 1–1000000; xp: целое 0–10000000. Это технические пределы импорта, не подтверждение правил.
- speed: непустой объект; допустимы walk/burrow/climb/fly/swim, целые 0–10000 футов. Порядок полей нормализуется. Отсутствующая скорость не подставляется автоматически.
- abilities: все шесть str/dex/con/int/wis/cha, целые 1–30; фиксированный порядок хранения.
- challenge: строка 0, 1/8, 1/4, 1/2 либо целое 1–30 в строковом виде. Числа и произвольные дроби запрещены.

Формула хитов, атаки, языки, чувства, навыки, иммунитеты и особенности пока только в тексте; автоматический бой не реализован. XP и challenge проверяются по структуре, соответствие таблице опыта автоматически не проверяется. Истинность каждого материала требует сверки источника.

Отчёт API дополнен structuredMonsters. После импорта всех текущих пакетов: 10 записей — 1 ссылка, 2 заклинания, 5 предметов, 2 существа. Редакция остаётся 2014; полный объём неизвестен. Повторный импорт не меняет каталог или прогресс.

Русские краткие изложения и названия подготовлены для СКАЗ; происхождение, изменения и CC BY 4.0 указаны у каждой записи. Общее правило длительности повторено в описаниях. Истощение и прочие состояния пока не импортированы; полнота категории не заявлена.

```sh

node scripts/import-catalog.mjs catalog/srd51-conditions.json --apply
```

Необязательное поле mechanic допустимо только у kind=mechanic, запрещено для reference-only. Если оно присутствует, обязательны category=condition и effects: массив от 1 до 30 непустых строк до 2000 символов каждая. Повторы после обрезки пробелов и неизвестные поля запрещены. Порядок эффектов сохраняется, так как это порядок чтения правил. Действия, отдых и другие категории пока не имеют этой структуры.

У Grappled links ссылается на Incapacitated: ссылка проверяется при импорте, независимо от порядка записей в пакете. Импорт одной записи захвата без её зависимости отклоняется. Ссылки доступны через API и кнопки связанных материалов в карточках. Effects — описания, не исполняемые команды: состояния не меняют лист автоматически.

GET `/api/catalog/entry?id=...` находит материал по устойчивому ID и возвращает `{entry,related:[{id,kind,name}]}`. Один обязательный параметр id; неизвестные/повторные параметры — 400, неверный ID — 422, отсутствующая запись — 404, повреждённая связь — 409. Связанные карточки открываются с возвратом к предыдущей, без сброса поиска. Закрытая карточка или другая форма не заменяется поздним ответом. Это переход между справочными материалами, не применение эффекта.


## Установка проверенной подборки из интерфейса

«Справочник → Проверенная подборка 2014» показывает категории, общее число, новые и совпадающие записи. Кнопка добавляет опубликованные пакеты одной транзакцией. Сервер читает только фиксированный список файлов из catalog, без личных файлов и манифестов. При конфликте занятого ID ничего не меняется. Игра и её ревизия не изменяются. Повтор после потери ответа безопасен: идентичные записи не дублируются. Установка явная, не запускается сама при старте.

GET `/api/catalog/bundled` возвращает `{version,categories,total,added,unchanged,ruleset,complete:false}` после проверки состава и конфликтов без записи. POST туда же с защищёнными заголовками и строго `{version}` устанавливает только просмотренную версию (SHA-256 содержимого подборки); если исходники изменились — 409 и нужен новый предпросмотр. Неверные поля — 422. Ответ содержит applied/added/unchanged/total/version. Это отдельная идемпотентная операция каталога; не команда изменения персонажа и не часть истории игровых ресурсов.
