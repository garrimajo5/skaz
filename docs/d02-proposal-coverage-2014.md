# Структурный свод D02

Refs #77. Роль content. [Реестр](../catalog/d02-proposal-coverage-2014.json) сверяет семь основных отчётов с исходным effective-m0-review: 283 группы, 583 наблюдения, 593 исходные атрибуции. Каждая группа представлена ровно один раз; исходные ID и порядок sourceIds сохранены. Разделы:22 группы рас,257 бестиария,4 предметов.

Уточнение гранулярности Genasi и две группы орфографических алиасов — три ссылки на уже существующие группы, а не дополнительные единицы каталога. Четыре дочерних предложения Genasi не увеличивают знаменатель. Десять групп с другими решениями корневого review находятся вне этого D02-свода.

Структурная сверка **не принимает** идентичность, полные правила, версии, переводческие права или алиасы. `accepted=false`, `complete=false`, `approvedDenominator=null`, принятых канонических единиц0. Наличие предложения для всех283 групп не закрывает D02, #77, M0 или полноту каталога. Нельзя суммировать неоднородные показатели публикационных свидетельств как единый процент полноты.

Воспроизведение: `node scripts/review-d02-proposal-coverage-2014.mjs`; восемь тестов `tests/d02-proposal-coverage.test.mjs` проверяют воспроизводимость и отказ при дубле группы/наблюдения, изменении массива источников, чужой группе/отчёте, осиротевшем уточнении и повышении приёмки. Отсутствующий основной отчёт остаётся явным пробелом. Десять входов закреплены LF SHA.

Следующий шаг — закрывать конкретные missingEvidence/fullRules/version/rights в исходных отчётах; отдельно сохраняются прочие решения identity-review. Runtime/профили не меняются, app/browser/Android выпуск неприменим.

Рефлексия: исторические отчёты имеют разные формы units/observations/sourceId; явный адаптер сохраняет исходные массивы вместо общей нормализации. Предложение — использовать этот свод как структурный контроль при дальнейших правках отчётов; польза в обнаружении потери/двойного счёта, затраты восемь быстрых тестов, риск ложной полноты снижен отдельными false/null. Планировщику предложено испытать на следующем источниковом пакете; общие инструкции не изменены.
