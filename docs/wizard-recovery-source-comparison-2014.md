## Условия для будущей автоматизации

Потраченные ячейки выбираются явно после короткого отдыха. Обычная частота — один раз в день; сумма кругов выбранных ячеек не больше половины **уровня волшебника** с округлением вверх; круг каждой не выше5. Это не количество ячеек и не половина суммарного уровня мультикласса. Пример источника с Wizard4 допускает одну ячейку2 или две ячейки1.

Это не автоматическое полное восстановление на каждом коротком отдыхе. Точная календарная граница «дня», автоматический сброс при долгом отдыхе/рассвете и маршрутизация PactMagic не установлены этим фрагментом. Такие решения нельзя вывести из названия отдыха или общей многоклассовой таблицы.

В JSON пять вымышленных случаев для game-design/backend: две комбинации исходного примера, Wizard5/Fighter3 с бюджетом3, превышение суммой4 и явно вручную выданная ячейка6. Игровые отклонения дают предупреждения/ручной путь, не обязательное согласование мастера. Правила технической целостности/конфликта/повтора остаются обязательными. Это примеры приёмки будущей реализации, не работающий recovery-API.

Существующий `wizard-arcane-recovery` остаётся manual и не переписан; SHA русского текста/происхождениеSRD53 сохранены. Лицензионная основа имеющегося текста — конкретный SRD; совпадение выбранного цифрового фрагмента не лицензирует весь сайт или PDF. Личный лист не читался. Каталог/деноминатор/полнота классов/матрицаЭдвина и runtime-приёмка этим не закрываются.
