## Существенные различия

- Сосуд гения, звёздная карта, внешность роя, драконье происхождение и другие таблицы не заменяют связанные механические части текста. Название таблицы не доказывает, что весь раздел — декоративное описание.
- Среды обитания друида — ссылки на существ, а не новые существа. Блоки спутников Grim Hollow и UA Giant Options сохраняют источник даже после нового h2.
- Воин: улучшения Renegade относятся к LoR; источник Shieldbearer найден в явной ведущей подписи styled span. Заголовок/anchor сам по себе не определяет источник.
- Нарушение клятвы паладина — компонент правил, а не автоматическое наказание персонажа. Runtime не меняется.
