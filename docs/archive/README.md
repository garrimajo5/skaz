# Архив общего плана и выпусков

Срез 21.11.2026 до сокращения стартового контекста. Полные архивные файлы
лежат непосредственно в docs/: так сохраняется исходная база относительных
ссылок, включая ссылки на код, QA, источники и соседние отчёты. Это архив,
а не обязательный пакет чтения при запуске роли.

- [История DEVELOPMENT_PLAN](../DEVELOPMENT_PLAN.archive-2026-11-21.md).
- [История deployment](../deployment.archive-2026-11-21.md).
- [Манифест исходного commit, SHA256 и размеров](context-history-2026-11-21.json).

Все байты исходных Git-файлов сохранены, включая незавершённые задачи,
решения, ограничения, повторения и исторические неточности. Архив не исправлять
задним числом. Более новые решения записывать в соответствующем актуальном
документе/issue со ссылкой на прежнее свидетельство. Старое «текущий» и старые
разрешения не являются утверждением о сегодняшнем сервере или новым доступом.

## Где искать важное

| Вопрос | Актуальный вход | Архивный поиск при необходимости |
| --- | --- | --- |
| Цель, выбор задачи, приёмка | PROJECT_GOAL, ROADMAP, governance/WORKFLOW и CONSTRAINTS | «решение владельца», «уточнение», номер issue |
| Следующий шаг источников | DEVELOPMENT_PLAN → профильная передача | #77, D03, D05, Wizard/Artificer |
| Распознавание и ручной профиль | #80/#81/#82 и связанные контракты | M0 #80, nullable, unknown, PR104 |
| Выпуск и незавершённый кандидат | deployment: текущий runtime, PR104 | SHA или дата конкретного выпуска |
| Старые backup/env/совместимость | deployment: порядок и откат | SHA, backup, capability, ledger |
| Устройство сервера и эксплуатация | deployment: устройство и порядок | «Устройство», «Эксплуатация», «Обновление» |
| Доказательства старых проверок | Точный PR/профильный отчёт | Название сценария, дата, SHA; не читать весь журнал |

Искать адресно, например `rg -n 'PR104|capability' docs/deployment.archive-2026-11-21.md`,
затем читать нужный раздел целиком с условиями. Не объявлять сокращённый индекс
полным перечнем исторических решений.

## Проверка сохранности

`python scripts/verify-context-archives.py` сравнивает архивы с Git-объектами
указанного commit и SHA256 манифеста, печатает размеры текущих документов.
Это проверка байтов/объёма, не точный токенизатор и не доказательство процента
экономии всего чата. Проверка смысловой сводки остаётся частью PR review.
