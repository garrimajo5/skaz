Задача #77, роль: специалист по контенту D&D. Реестр фиксирует обнаруженные материалы и границы проверки. Это не утверждённый полный каталог и не отчёт о завершённом переносе правил.

## Версии бестиария

Оба списка получены в одном блоке 17.11: по 2875 страниц, 2610 общих ID, по 265 страниц только в одном варианте. Объединение содержит 3140 страниц. Оно не означает 3140 уникальных игровых сущностей: разные версии должны сохраняться до содержательной проверки.

Сопоставление английских названий выделяет 286 различающихся групп: 231 группа один-к-одному, 12 два-к-двум, 1 три-к-трём, 21 только classic и 21 только multiverse. Это кандидаты для разбора версий и переименований, не доказательство равенства правил. Порядок строк и переименование slug не создают новую страницу или новую группу различий сами по себе.

`catalog/dndsu-bestiary-variants.json` сохраняет оба индекса, URL запросов, SHA, состав групп и `rulesEquivalence: unverified`. Основной реестр отмечает `observedVariants` и не складывает общие страницы дважды.

## Другие единицы учёта — не прибавлять к страницам

- 18 статей [инвентаря](https://dnd.su/articles/inventory/) — не 18 предметов.
- 25 статей [механик](https://dnd.su/articles/mechanics/) — не 25 отдельных правил и не исчерпывающий список механик.
- 186 наблюдений строк таблиц: 13 доспехов/щитов, 37 оружий, 99 снаряжения, 37 инструментов. Это частичная инвентаризация четырёх статей, а не утверждённые канонические записи. У каждой строки есть название, цена как текст, URL и источники статьи; canonicalCatalogId пока null. Для многоисточниковой статьи её источники не выдаются за точную атрибуцию каждой строки.
- 2962 заголовка внутри 13 классов, включая Изобретателя. Это навигационные свидетельства для дальнейшего разбора подклассов и умений. 1057 исключены как homebrew по якорю или группе источника, включая 343 заголовка Midgard. UA/playtest дополнительно определяется явным источником, а не только префиксом якоря. Заголовок может быть описанием или навигацией, поэтому число не является знаменателем умений. Пустые заголовки учитываются отдельно; комментарии сайта не включаются.

Нельзя складывать страницы, статьи, строки таблиц и заголовки в один показатель покрытия. Механики, подклассы/умения и обычное снаряжение остаются в `unindexedScopes`: есть свидетельства обнаружения, но каноническая инвентаризация не завершена.

## Идентичность, происхождение и использование

ID страницы строится по разделу, числовому ID и явному multiverse-префиксу. Slug и перевод не определяют ID. Повтор одного ID отвергается. Несколько локальных кандидатов сохраняются без автоматического выбора версии. Редакция не определяется одним годом выпуска книги.

Для каждой страницы раздельны запись, полный текст, поля, автоматизация и арт. Принятый арт не подтверждает правила. Неизвестный источник и конфликт сведений об источнике не проходят молча. URL другого домена, next.dnd.su, с учётными данными или нестандартным портом не принимается.

`reusePermission: not-established-for-reference-text` означает, что публичная страница не устанавливает разрешение на копирование полного текста. У всех 633 локальных записей сохранены собственные URL, название/версия источника и usage; хеш bundled catalog связывает реестр с исходными полями атрибуции. В текущем локальном каталоге 632 записи с usage cc-by-4.0 и одна reference-only. Этот статус локального материала не переносится автоматически на перевод или другую страницу dnd.su.

## Файлы и воспроизведение

- `catalog/dndsu-source-register.json`, `catalog/dndsu-class-discovery.json`: исходные метаданные источников и списка классов.
- `catalog/dndsu-rule-index-2026-11-15.json`: прежний снимок трёх разделов с локальными кандидатами.
- `catalog/dndsu-additional-discovery.json`: черты, предыстории, расы, ссылки статей инвентаря и механик.
- `catalog/dndsu-equipment-discovery.json`: частичные наблюдения таблиц снаряжения.
- `catalog/dndsu-class-headings.json`: навигация классов без текстов правил.
- `catalog/dndsu-bestiary-variants.json`: сравнение вариантов.
- `catalog/scope-register-2014.json`: объединённый реестр, ссылки на разные единицы учёта и SHA входов.

Из корня репозитория:

```sh
node scripts/catalog-scope-register.mjs
node --test tests/catalog-scope-register.test.mjs tests/catalog-additional-discovery.test.mjs tests/catalog-equipment-discovery.test.mjs tests/catalog-bestiary-variants.test.mjs tests/catalog-class-headings.test.mjs
```

Повторная сборка из неизменённых сохранённых JSON должна совпадать побайтно. Аргумент после имени генератора задаёт другой выходной файл для безопасного сравнения.

Для повторного извлечения из локальных HTML-снимков:

```sh
node scripts/catalog-additional-discovery.mjs data YYYY-MM-DD output-additional.json
node scripts/catalog-equipment-discovery.mjs data YYYY-MM-DD output-equipment.json
node scripts/catalog-bestiary-variants.mjs data YYYY-MM-DD output-variants.json
node scripts/catalog-class-headings.mjs data/class-headings YYYY-MM-DD output-class-headings.json
```

Первый ожидает source-feats/backgrounds/race/inventory/mechanics.html; второй — equipment-95/96/98/100.html; третий — bestiary-classic/multiverse.html; четвёртый — class-<числовойID>.html. Пути и SHA находятся в соответствующих манифестах. `fetch-dndsu-class-headings.mjs <папка>` получает только 13 публичных страниц согласованного списка, без авторизации и переходов на другие URL. Остальные исходные HTML текущего блока остаются в игнорируемом data; обновление снимка требует явной даты. SHA относится к сохранённому UTF-8 HTML, включая динамическую обвязку сайта, а не к каноническому тексту правил.

## История: остаток после первоначальной сборки

## Проверки и рефлексия

Тесты охватывают исключения источников, неизвестные и конфликтующие источники, версии и алиасы, изменения slug/порядка, двухколоночные таблицы, границы статьи против комментариев, контекст HB/UA, изменившуюся разметку и разделение единиц покрытия. Итог: 45/45 тестов, синтаксическая проверка десяти скриптов, npm check/build и git diff --check успешны. Все семь итоговых JSON-манифестов повторно сгенерированы побайтно идентично; доказательства переданы в PR.

Изменений приложения, кампаний и VPS нет; браузерное UI QA и выпуск неприменимы. Это аудит контента, не новая опубликованная функция.

Рефлексия: главная полезная находка — 265 classic-only страниц, невидимых прежнему аудиту. Лишняя работа возникла из различий разметки: multiverse-префиксы, две колонки инструментов и пустые заголовки. Предложение планировщику: испытать обязательную проверку единицы учёта и парного снимка вариантов перед подсчётом покрытия. Польза — предотвращение ложной полноты и дублей; затраты — малый набор фикстур; риск — устаревание HTML, поэтому разбор завершается ошибкой при известных несоответствиях. Решение планировщика ещё не получено, общие инструкции не менялись.

## История расширения: предложение по барду для независимой проверки

В `catalog/dndsu-bard-scope-proposal.json` выделены 14 базовых умений, 8 официальных коллегий и 35 умений коллегий. Это предложение роли content, не принятый знаменатель и не автоматизация. У трёх опциональных умений сохранён маркер TCE. Для коллегий мечей/очарования/шёпотов, красноречия/созидания и духов записаны явные источники разделов; PHB для базовых умений и коллегий доблести/знаний — наследование источника страницы, отдельно обозначенное как основание.

Пример опасного ложного совпадения: заголовок «Истории духов» с советом рассказчику исключён как отдельное умение; «Истории с того света» сохранено. Одинаковые названия умений разных коллегий имеют разные идентификаторы наблюдений. Это не устойчивые ID рабочего каталога: canonicalCatalogId пока null; назначение и алиасы потребуются после приёмки. Номера уровней из вводной строки сохраняются только как observedInitialLevels: повторные улучшения, условия, исключения и полная прогрессия этим не проверены. Непривязанный заголовок не превращается в выдуманное значение.

Повторная сборка предложения: `node scripts/catalog-bard-scope.mjs`. Проверка: `node --test tests/catalog-bard-scope.test.mjs`. В навигационном манифесте дополнительно сохранены 273 упоминания источников у 267 заголовков: 135 сопоставлены с реестром, 138 остаются неразрешёнными. Исходное написание сохранено; типографский апостроф и невидимые форматирующие знаки не создают новый источник.

Классификация остальных 11 классов добавлена ниже; нерешённые вопросы источников остаются явными. Геймдизайнер/QA независимо проверяют предложение барда; оно не применяет изменения к персонажам.

## Предложение по варвару

В `catalog/dndsu-barbarian-scope-proposal.json` выделены 16 базовых умений, 9 путей и 40 умений путей. Включён Путь великана из Bigby Presents: Glory of the Giants: ограничение одной PHB привело бы к пропуску согласованного каталога 2014. Требование к происхождению бушующего в бою и ссылка на шипованный доспех учтены отдельными типами, не потеряны и не посчитаны новыми классовыми умениями.

У двух опциональных умений сохранён маркер TCE. Все записи имеют `sourceCompleteness: not-verified-in-full-text`: источник заголовка не подтверждает источники всех вложенных вариантов (например, дополнения тотемного воина). Оба предложения строятся общей проверяемой процедурой по явно заданным границам классов; неизвестный источник раздела не заменяется PHB. Классификация воина и остальных 10 классов добавлена ниже. Барда и варвара принимает независимый проверяющий, а не автор предложения.

Проверены origin, запрет redirect, тип ответа, тайм-аут и лимит16MiB до записи. Остаток: полные тексты и источники вложенных правил, варианты тотемов/договоров, таблицы заклинаний подклассов, замены спутников и статблоки, таблицы воспроизводимых предметов; три источника рас, права переводов, дедупликация версий и окончательный знаменатель.
