Задача #77, роль: специалист по контенту D&D. Это промежуточный реестр обнаружения, а не принятый полный каталог и не отчёт о завершённом переносе правил.

15 homebrew исключены. 4349 остальных страниц — **кандидаты**, не утверждённый знаменатель. 575 страниц имеют кандидатов на соответствие локальным ID. Это не количество полностью перенесённых правил. Реестр не сертифицирует полный текст ни одной записи; это статус проверки данным инструментом, а не утверждение, что в приложении нет полных правил.

70 источников извлечены из общедоступных метаданных фильтров [заклинаний](https://dnd.su/spells/), [бестиария](https://dnd.su/bestiary/) и [предметов](https://dnd.su/items/). Все числовые ID источников прежнего снимка расшифрованы. Классы обнаружены по [индексу классов](https://dnd.su/class/). Полные тексты страниц не копировались.

## Файлы и воспроизведение

- `catalog/dndsu-source-register.json`: названия, числовые ID, группа издания, разделы наблюдения и SHA исходных HTML.
- `catalog/dndsu-class-discovery.json`: зафиксированные метаданные классов, спутников и исключённого homebrew.
- `catalog/dndsu-rule-index-2026-11-15.json`: прежний снимок трёх разделов с кандидатами локальных соответствий.
- `catalog/scope-register-2014.json`: объединённый результат; отдельно все 633 локальные записи и их происхождение.
- `scripts/catalog-scope-register.mjs`: воспроизводимая сборка из этих входных файлов и bundled catalog.

Из корня репозитория:

```sh
node scripts/catalog-scope-register.mjs
node --test tests/catalog-scope-register.test.mjs
```

Для сравнения без перезаписи используйте аргумент пути выходного JSON. В реестре записаны SHA-256 входов и локального каталога. Повторная сборка на неизменённых входах должна совпадать побайтно. Это воспроизводимость сохранённого снимка, не автоматическая повторная выгрузка текущего сайта. Дата исходного снимка не заменяется датой генерации.

## Политика идентичности и покрытия

ID страницы строится по домену, разделу и числовому ID, а не по изменяемому slug или переводу. Повтор того же ID с другим названием отвергается. Несколько локальных кандидатов сохраняются: генератор не выбирает автоматически одну версию и не объединяет игровые эффекты. Явные алиасы уже отражены в исходном индексе; версионные решения требуют проверки контента.

Для каждой страницы разделены: наличие кандидата записи, полный текст, поля метаданных, автоматизация и арт. Принятый арт не подтверждает правила. Неразрешённый источник даёт `needs-source-review`, homebrew исключается даже при похожем имени и известном источнике. Внешний домен и `next.dnd.su` не принимаются. Издание в фильтре 2014 остаётся кандидатом до проверки; год выпуска сам по себе редакцию не определяет.

`reusePermission: not-established-for-reference-text` означает, что присутствие публичной страницы не устанавливает разрешение на копирование её полного текста. У локальных записей сохранено собственное поле `source.usage`. Эти два статуса нельзя подменять друг другом.

## Проверки и применимость выпуска

Семь тестов проверяют неизвестные источники, исключение homebrew, запрет сторонних/2024 URL, повтор страницы с переименованным slug, множественные алиасы, несуществующие локальные ID и разделение статусов покрытия. Повторная сборка совпала по SHA-256. Общие check/build выполнены отдельно, результат фиксируется в PR.

Изменение добавляет документы и аудит; приложение не читает новый реестр. Игровые данные и опубликованный runtime не меняются, выпуск на VPS и браузерная проверка интерфейса к этому результату неприменимы.

## Рефлексия для планировщика

Результат: числовые источники стали проверяемыми, границы полноты теперь видны в данных. Лишняя работа: широкий старый аудит пришлось разбирать отдельно от списка категорий. Предложение: испытать на следующей категории правило «сначала индекс источников и границы, затем перенос правил». Польза — меньше ложных пропусков и переделок; затраты — один небольшой снимок метаданных; риск — устаревание снимка, поэтому обязательны дата и SHA. Решение планировщика ещё не получено; общие правила этим предложением не меняются.
