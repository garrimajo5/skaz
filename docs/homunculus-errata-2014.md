# Инфузия «Слуга-гомункул» в эрратах 2014 — #77 D05

Две официальные эрраты имеют разные области. В реестре сохранены версия, указатель, число страниц, SHA-256 исходного PDF и отпечатки нормализованных страниц. [Проверяемый отчёт](../catalog/homunculus-errata-2014.json).

| Источник | Что установлено |
| --- | --- |
| [Eberron v2.0, PDF 1, книга 62](https://media.wizards.com/2020/dnd/downloads/ERftLW-Errata.pdf#page=1) | Убрано требование 6-го уровня изобретателя. Для сердца подходит самоцвет или кристалл стоимостью от 100 зм. Блок параметров использует бонус мастерства владельца. |
| [Eberron v2.0, PDF 1–2, книга 62](https://media.wizards.com/2020/dnd/downloads/ERftLW-Errata.pdf#page=2) | Гомункул ходит сразу после владельца на той же инициативе. Движение и реакция самостоятельны. Иное действие вместо Уклонения обычно требует бонусного действия владельца, а при его недееспособности существо выбирает само. При смерти владельца или гомункула существо исчезает, оставив сердце. На второй странице приведён заменённый блок характеристик. |
| [Tasha v1.0, PDF 1](https://media.wizards.com/2021/dnd/downloads/TCE-Errata.pdf#page=1) | В этой эррате нет правки с названием «Слуга-гомункул». Текст самой книги Tasha и эквивалентность изданий остаются для отдельной сверки. |

Для синтетического случая «изобретатель 3» проверка исправленной версии Eberron учитывает снятое требование уровня. Известная инфузия, её активное применение и расход предмета остаются отдельными фактами. Выбор, согласованный с мастером, сохраняется. Источник для округления общих ячеек отслеживается отдельно. [Границы мультикласса](artificer-multiclass-sources-2014.md).

Эрраты отмечают личную печать и копирование. Исходные PDF остаются в локальном захвате. Для каталога записаны указатели на источник и выводы о версии.

```sh
python scripts/audit-homunculus-errata-2014.py <папка-захвата> --output catalog/homunculus-errata-2014.json
python -m unittest discover -s tests -p test_homunculus_errata_2014.py
```

Папка захвата содержит два PDF и `capture.json` с URL, статусом, размером, SHA-256 и временем. Проверено с Python и `pypdf 6.21.4`.
