# Ready и повторный bonus-фрагмент — #77/D05

[Отчёт](../catalog/ready-bonus-context-2014.json) проверяет две secondary-наблюдения (3абзаца), не выдавая их за два новых полных правила. Ready17 — spell-excerpt, а bonus18 — сокращённое повторение уже проверенного bonus14. Оба исходных heading/bodySHA сохранены; второй способности не создано, primary bonus-параграф повторно не извлекался.

Полный combat Ready взят с **SRD93→94**, доSearch, с контекстом триггера и срока. Отдельно сохранён весь Reactions91 доMovement and Position: восстановление к началу следующего своего хода, а не по границе условного раунда. PHB2014errata v3.0PDF4 исправляет второе предложение Ready на срок до начала следующего хода; выбранный SRD уже содержит эту поправку. Secondary-excerpt этого полного предложения не содержит — это предел фрагмента, не скрытая приёмка всего действия.

Обычное подготовленное заклинание накладывается при Ready и удерживается с концентрацией; при триггере можно выпустить его реакцией после завершения триггера либо проигнорировать триггер. Новая реакция не выдаётся. Для обычного spell-ready требуется время1действие и сохраняются обычные доступ/компоненты; Ready не добавляет заклинание в известные или классовую подготовку. Даже обычно неконцентрационное заклинание требует концентрации во время удержания; прежняя концентрация заканчивается.

Расход ячейки для обычного slot-spell следует из cast-as-normal и уже проверенного Spell Slots. При выпуске нет второго расхода; срыв концентрации/отсутствие триггера не дают автоматического возврата. Это **не** процедура долгого сотворения с неистраченной ячейкой. Предметные действия/заряды требуют своих правил, их timing/refund не выводится.

**Оговорка перевода:** в общей фразе secondary17 отсутствует явный release-with-reaction, хотя реакция есть в следующем примере. Пропуск сохранён, исходник не исправлен молча. Ограничение bonus18 действует до/после в том же ходу, включая бонусное заклинание-заговор; не всякое неспелловое бонусное действие и не весь раунд.
