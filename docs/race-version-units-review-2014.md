## Основание и результат

[Официальный FAQ2022](https://www.dndbeyond.com/posts/1201-faq-for-mordenkainen-presents-monsters-of-the) прямо различает прежние и новые версии рас, сохраняет старые и не переводит существующих персонажей автоматически. [Индекс издателя](https://www.dndbeyond.com/species) даёт отдельные идентификаторы и подписи книг. Сохранены только29 библиографических записей по выбранным12 именам, URL и SHA исходного HTML; описания, способности и изображения в Git не копировались.

Для11 пар обе публикационные ссылки найдены непосредственно в индексе. Для голиафа вторичная source111-атрибуция не совпадает с подписью старой индексной записи (Elemental Evil). Подмена одного источника другим запрещена. Вместо этого [официальная эррата Volo v3.0, лист1](https://media.wizards.com/2021/dnd/downloads/VGtM-Errata.pdf#page=1) прямо указывает его раздел на странице109 книги. Байты PDF совпали с ранее закреплённым SHA5772849a…c8a06a; текст заголовка подтверждён pypdf. Это подтверждает наличие в публикации, **не** тождество полных правил Elemental Evil/Volo или точную эррату вторичного текста.

Ссылки для Firbolg/Bugbear/Kobold (шесть) дополнительно открыты: версии MotM перенаправили на marketplace, Volo — на legacy landing page. Полные правила не прочитаны и не объявлены проверенными. Для остальных индексных записей отдельно открытие деталей не заявляется.

Файлы:

- [Первичный индекс](../catalog/race-publication-identity-evidence-2014.json):29 метаданных, выбранные имена, SHA HTML, метод и ограничения.
- [Голиаф](../catalog/goliath-publication-reference-2014.json):точная публикационная ссылка/страница и SHA, связанный с прежним манифестом эрраты.
- [Предложения](../catalog/race-version-unit-proposals-2014.json):12 групп,24 наблюдения и24 **предлагаемые** единицы; принятых единиц0, знаменательnull.

В каждом предложении сохранены sourceId, observationId и отдельный proposedVersionKey. `automaticMerge:false`, `automaticCharacterMigration:false`, `accepted:false`; полные правила/эррата/права перевода остаются непроверенными. Метка Legacy не означает редакцию2024: часть MotM-вариантов уже помечена так после новых публикаций. Их нельзя исключить одним поиском этой метки или молча заменить новую версию в старом профиле.

## Воспроизведение и проверки

```sh
node scripts/propose-race-version-units-2014.mjs
node --test tests/race-version-unit-proposals.test.mjs tests/catalog-input-hashes.test.mjs
python -m unittest discover -s tests -p test_race_index_evidence.py
node scripts/verify-catalog-input-hashes.mjs
```

Первичную страницу можно повторно разобрать локально (динамический HTML может изменить SHA; сравнивать также выбранные метаданные):

```sh
python scripts/extract-race-index-evidence.py --html <temporary-species.html> --names firbolg,aasimar,triton,kenku,tabaxi,bugbear,goblin,kobold,hobgoblin,goliath,lizardfolk,orc --output <temporary-evidence.json>
```

Реально сохранённый HTML проверен по SHA и всем29 извлечённым записям. Публикационное свидетельство голиафа ведётся отдельно и не подменяется этим парсером. Генератор предложений по умолчанию readonly; после проверки входов пересборка явным `--write`. Пять входов и зависимость эрраты закреплены SHA, отчёт не включается в runtime.

Проверки автора:10/10 Node (6 новых,4 общих SHA),5/5 Python. Отрицательные сценарии: одинаковое имя другой категории/книги/редакции; отсутствие источника; двойная атрибуция; дубликат первичного ID/URL; ложный домен; подмена имени; неверная страница/SHA эрраты; отсутствие голиаф-свидетельства оставляет пару unresolved. Входные данные не мутируются. Самопроверка не независимая приёмка.

## Передача

QA/content: независимо проверить первичные соответствия24 наблюдений и отрицательные сценарии. Геймдизайнер: подтвердить модель самостоятельного выбора версий без автоматической миграции персонажа и запрета личных исключений. Далее — остальные межисточниковые группы, точные версии текстов и права; эти12 предложений не вычитаются из принятого знаменателя до приёмки. Изменений интерфейса и runtime нет: браузер, Android и VPS для этого артефакта неприменимы. M0 закрывает владелец.

Рефлексия: первичный индекс позволил проверить пакет вместо повторного обхода одинаковых вторичных имён. Первоначальная остановка сопоставленияVolo оказалась различием регистра; исправлена, остальные несовпадения не нормализованы произвольно. Голиаф потребовал отдельного первичного свидетельства, а не ослабления условия. Предложение планировщику: в следующих пакетах версий сначала искать первичный индекс и явно отделять точную атрибуцию от совпадения имени; затраты малы, риск — принять индекс за полный текст, поэтому статусы остаются раздельными. Решение планировщика не принято.
