# IMR: границы версий и отдельные свидетельства правил

20.11.2026, #77. Все данные ниже — неподключённые свидетельства/кандидаты. Runtime, профили, база, каталог приложения и разрешение публикации текста не изменены. Полнота каталога и знаменатель не приняты.

## Версии

`imr-version-boundaries-2014.json` и производный `imr-version-review-2014.json`:18 наблюдений девяти имён,94 поля заголовков,11 строк первичного индекса. Original URL/ID сохранены, MPMM читается по отдельному multiverse-пути. У шести групп заголовки различаются; у трёх совпадение заголовков не доказывает равенство умений. Число в URL не определяет версию.

Первичные страницы Boggle17224 и Redcap17300 перенаправили на MPMM marketplace;2556122 и2556141 обозначены legacy. Остальные семь выбранных строк обозначены legacy. Редирект и подпись источника не считаются прочитанным полным статблоком. Crown of the Forest остаётся без полного текста. Контекст версий: [официальное пояснение legacy](https://www.dndbeyond.com/legacy).

Проверка18 сохранённых публичных HTML сверила94 поля. Парсер выбирает точную card по data-id и data-cardlink, проверяет английское имя и source plaque: соседний одноимённый статблок не может подменить выбранный. Нулевая скорость ходьбы не означает отсутствие иных скоростей. Исходные HTML находятся только во временной папке, в Git не включены.

## Модели NPC и эррата — свидетельства для M4

`imr-warlock-models-2014.json`: четыре выбранные модели Fiend/Great Old One VGM/MPMM. У VGM раздельно учитываются ячейки, восстановление и врождённое применение; у MPMM лимит1/день относится к каждому перечисленному заклинанию. Неуказанный параметр — null, не ноль. Mage Armor ограничено self и at will. Это не полный список заклинаний и не расчёт класса игрока. Аудитор сверил четыре реальные сохранённые страницы;17 тестов вместе с HTML-парсером.

`vgm-mtf-selected-errata-2014.json`:12 выбранных единиц исправлений,11 кандидатов существ, в том числе две записи таблиц окружения для Flind, не два новых существа. Источники: [VGtM v3.0](https://media.wizards.com/2021/dnd/downloads/VGtM-Errata.pdf) и [MTF v1.0](https://media.wizards.com/2020/dnd/downloads/MTF-Errata.pdf). SHA обоих PDF закреплены. Проверены первичные формулировки/условия;11 вторичных статблоков в этом пакете не сверялись. У Orcus удаление одной аннотации DC не означает отсутствия всех спасбросков. Разрешение личной печати PDF не является разрешением перепубликации правил.
