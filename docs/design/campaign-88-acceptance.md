- Обзор использует открытые задания и их первые незавершённые этапы. Ссылка на прошлую встречу открывает существующий архив, а возвращение сохраняет игровой режим, выбранную сессию и фокус. Дневник и история используют действующие экраны.
- В Edge на вымышленной игре проверены создание, поиск по тексту, чтение на клавиатуре, правка гипотезы, известная и неизвестная встреча, связи, разница «Переправа QA → Место неизвестно» в истории.
- Конфликт 409 переживает reload. После сверки форма хранит новые правки на актуальной ревизии. При восстановлении создания пустое отношение остаётся неизвестным. Успешный серверный запрос с потерянным ответом повторяется ровно один раз с прежним ID.
- Большой пакет больше 5 МиБ импортирован и повторён после reload с тем же файлом. Осталась одна новая кампания, архив открывается по новому ID и показывает исходный номер. Файл остаётся в памяти браузера, для повтора сохраняется отпечаток и квитанция.
- Индивидуальный сценарий подтвердил 403 при понижении мастера до игрока, отсутствие кнопок правки у игрока и исчезновение карточки при отзыве доступа. Три темы проверены при 320×780, 390×844, 844×390, 820×1180 и 1180×820 с клавиатурой или браузерным касанием. Android-устройство не подключалось, физическая проверка Xiaomi относится к #15 по плану #79.

Два независимых ревью, команды и пошаговые результаты сохранены в [PR #300](https://github.com/garrimajo5/skaz/pull/300#issuecomment-7129134457). Краткая проверка типов — `npm run check:campaign-people`. [Защищённый выпуск и откат](https://github.com/garrimajo5/skaz/issues/88#issuecomment-7129239809).
