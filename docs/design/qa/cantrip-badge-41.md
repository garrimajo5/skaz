# Обозначение заговора на четырёх экранах

QA выпущенного кода `4f092b8` на вымышленной RAM-игре. Клиентские и серверные файлы совпадают с выпуском. Проверка выполнена в отдельном Edge на согласованном `127.0.0.1:4337`. В игре подготовлены две карточки из проверенной подборки D&D 2014.

| Поверхность | Что подтвердилось |
| --- | --- |
| «Игра», три темы 820×1180 | «Волшебная рука» помечена ∅ с доступным именем «Заговор», «Огненный шар» — цифрой 3 с именем «3 круг». Действия подписаны «Применить · Без ячейки» и «Сотворить · 1 ячейка · 3 круг». |
| Книга | Есть отдельные заголовки «Заговоры» и «3 круг». Enter открывает карточку с текстом «Заговор». Escape возвращает в список. |
| Справочник | Поиск по английскому имени находит русскую карточку. В плитке и подробностях написано «Заговор». Категория, поиск и открытие проверены касанием. |
| Применение и выбор ячейки | При «Применить» через Enter на 820×1180 запрос прошёл, ячейки не изменились и выбора круга не появилось. Для «Огненного шара» на 390×844 проверен ручной счётчик: доступны круги от третьего, тап по 3 и подтверждение сохранили расход 2→1. |

[Полярис](cantrip-badge-41/polar.png) · [Уголь](cantrip-badge-41/coal.png) · [Атлас](cantrip-badge-41/atlas.png).

102 проверки клиента Игры, каталога и серверного сотворения прошли. Действующий выпуск не менялся. Снимки и проверка относятся к Edge; физический Xiaomi и приёмка M2 отдельны.

Рефлексия QA. Соседство двух строк показывает, распознаётся ли обозначение, а проверка запроса дополнительно подтверждает отсутствие расхода. Предлагаю в будущих визуальных проверках затрат оставлять один реальный сквозной сценарий рядом со снимком. Основные издержки — загрузка арта и стабильный момент снимка.
