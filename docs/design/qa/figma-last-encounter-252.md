# Место последней встречи в списке персонажей — #252

Если у встречи было сохранено место без комментария, компактная карточка показывала «Последняя встреча неизвестна». Теперь в списке видны сохранённое место, комментарий и сессия, когда они известны. При отсутствии самой встречи отображается прежнее сообщение. Детальная карточка открывает исходное место по прежней ссылке.

[До](figma-last-encounter-252/before.png) · [после](figma-last-encounter-252/after.png), Полярис, 1180 × 820, вымышленная игра. Список получает название места только в активной кампании по существующему запросу. Переименование места видно при следующем чтении, ID и текст встречи сохраняются. Снимки из переноса используют сохранённый источник, если локальная ссылка отсутствует.

В Edge совпали девять сценариев трёх тем и размеров 1180 × 820, 411 × 740, 320 × 640. «Северные ворота» видны в компактной карточке при пустом комментарии. В карточке без встречи доступно состояние неизвестного. В подробностях открывается ссылка на «Северные ворота». Проверка типов, сборка и 194 целевых теста прошли.

На портретном Pixel_8 в Угле [«Северные ворота» видны в списке](figma-last-encounter-252/android-list.png). В карточке касание названия открыло [сохранённое место](figma-last-encounter-252/android-place.png). На обоих шагах ревизия 5, хиты 18, ячейки 2-го круга 2. Свои вкладка, проброс и стенд закрыты, исходные размер, плотность и поворот подтверждены.

Точный код ca68249 прошёл Linux с Nginx 2227/2227, проверку исходников и сборку. Независимое read-only ревью проверило контекст выборки, необязательное поле, ссылки и снимки. На VPS по журналу 280fe60. [Защищённый выпуск](https://github.com/garrimajo5/skaz/issues/252#issuecomment-7170014871) и приёмка M2 открыты.
