# Место последней встречи в списке персонажей — #252

Если у встречи было сохранено место без комментария, компактная карточка показывала «Последняя встреча неизвестна». Теперь в списке видны сохранённое место, комментарий и сессия, когда они известны. При отсутствии самой встречи отображается прежнее сообщение. Детальная карточка открывает исходное место по прежней ссылке.

[До](figma-last-encounter-252/before.png) · [после](figma-last-encounter-252/after.png), Полярис, 1180 × 820, вымышленная игра. Список получает название места только в активной кампании по существующему запросу. Переименование места видно при следующем чтении, ID и текст встречи сохраняются. Снимки из переноса используют сохранённый источник, если локальная ссылка отсутствует.

В Edge совпали девять сценариев трёх тем и размеров 1180 × 820, 411 × 740, 320 × 640. «Северные ворота» видны в компактной карточке при пустом комментарии. В карточке без встречи доступно состояние неизвестного. В подробностях открывается ссылка на «Северные ворота». Проверка типов, сборка и 194 целевых теста прошли. Нативная проверка и полный Linux выполняются.
