## Браузер и автоматические проверки

- Edge, имитация уменьшенной области 310, 320 и 175 CSS px в Угле, Полярисе и Атласе. При 175 px Tab последовательно довёл фокус до всех восьми строк, Shift+Tab вернул к полю. Задержанный ответ и ошибка 503 не забрали фокус, повтор показал результаты. При 71 px поле, «Найти» и закрытие получили отдельные цели от 44 px. Enter оставил фокус на «Найти» до восстановления высоты.
- Без клавиатуры снимки поиска на 1512×982, 1180×820, 820×1180 и 320×568 совпали с исходными побайтово. Без VisualViewport поиск и открытие карточки работают. В настоящем Edge при масштабе 150% включалась обычная компоновка. Диалог спасбросков от смерти сохранил свою компоновку.
- На 1512×982, 800×1280, 1280×800 и 320×568 по видимым кнопкам прошли «Лист персонажа» → «Магия» → «Инвентарь» → «Кампания» → «Справочник» → «Игра». Герой и сессия сохранились, горизонтального переполнения страницы не было.
- Linux Node v24.22.3, сборка, проверка синтаксиса, три проверки типов и 2 220/2 220 тестов с Nginx. Windows Node v26.13.0, 2 214 пройдено, 6 платформенных пропусков, 0 ошибок. SHA-256 Git-архива `c46643f609873e9e641a7b43de8139063780d27ea937d1da61372a87111d47e1`. SQLite, приватные `.env`, ключи и аудио в архив не попали.
- Независимое read-only ревью финального SHA прошло, 50/50 целевых тестов. Ревьюер просмотрел кадры альбома; на устройстве сценарий воспроизвёл исполнитель.
