# Поиск на карте при сохранении ресурса

[Задача #252](https://github.com/garrimajo5/skaz/issues/252) · [Правило стабильной компоновки](../visual-guidelines.md).

Начать расход ячейки в «Быстром доступе», перейти к «Карте» до ответа сервера и ввести запрос. В контрольной версии ответ пересоздавал форму, очищал запрос и сбрасывал фокус. Теперь форма остаётся на месте, карта запрашивает актуальные точки для той же игры после подтверждения. Сохраняется загруженный список, если он совпал с полученным. При отказе чтения виден результат ошибки.

Edge на вымышленной игре, 15 успешных сочетаний (1512×982, 1180×820, 820×1180, 844×390 и 390×844 во всех трёх темах). Сохранились сам элемент поиска, его координаты, запрос и фокус. Поиск после ответа находит точку, «Новое место» открывается при разрешённой записи, боевой пульт скрыт весь проход. Автоматический тест проверяет право записи, повтор без изменения списка, отказ чтения и смену кампании.
