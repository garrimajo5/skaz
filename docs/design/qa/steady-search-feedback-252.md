# Уведомление без сдвига поиска кампании

В низком окне 648×260 появление подтверждения сжимало поле поиска с 532,75 до 264,75 px и передвигало «Найти» влево на 268 px. Исчезновение подтверждения возвращало прежние размеры. Теперь при высоте окна до 260 px и ширине от 620 px правая колонка отведена заранее. В этой колонке подтверждение раскрывается поверх страницы, не участвуя в её раскладке. В остальных размерах работает обычное всплывающее подтверждение.

| Проверка | Результат |
| --- | --- |
| 620×246, 648×260, 760×300 и 411×740, три темы | В 12 сочетаниях поле, форма и «Найти» сохранили размеры и горизонтальное положение. Уведомление не перекрывало поиск. Центры поля, «Найти» и «Отменить» доступны для касания. |
| Tab, Enter, изменение высоты | В шести сочетаниях коротких размеров можно найти запись и отменить урон клавиатурой. При переходе 260 → 360 → 260 или 246 → 360 → 246 фокус остаётся на «Отменить». |
| Границы контекста | В трёх темах по 648×260 проверены активная проверка концентрации и смена экрана. Уведомление остаётся единственным, актуальным и не скрывает ответ концентрации. |
| Истечение времени | Уголь, 648×260. Автоматическое исчезновение через 12 секунд сохраняет поле, его ширину, запрос и фокус. Дополнительной записи нет. |

Edge, отдельная вымышленная игра, локальный сервер закрыт. Windows: `npm run check:campaign-people`, 24 целевых теста. Клавиатура проверена в Edge. Физическую приёмку на Xiaomi Pad 6 ведёт владелец.

Рефлексия. Для уведомлений измеряем положение поля до появления, во время показа и после скрытия. Проверка только доступности двух кнопок в момент показа пропускала скачок.
