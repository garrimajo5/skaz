## Почему кандидат остаётся черновиком

`scope-register-2014.json` закрепляет прежний SHA `art-coverage.json`, а воспроизведение исторической инвентаризации читает текущую штатную подборку. Новый ID изменяет обе входные версии. У 53 отчётов есть прямая привязка к историческому реестру. Смена нескольких SHA вручную не воспроизводит их доказательства. Следующий шаг — закрепить для исторического генератора его каталог и исходный отчёт покрытия отдельно от живой подборки, проверить точное воспроизведение и затем выпустить новый ID.
