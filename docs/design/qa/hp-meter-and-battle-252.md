# Шкала хитов и кнопка боя по Figma · #252

Сверены сохранённый кадр узла 3:3 на 1512×982 и вымышленная игра текущего выпуска 5a0db54. Свежий предпросмотр Code Layer вернул однотонный кадр. Для сравнения использован сохранённый кадр с SHA-256 01bd6fd73288e3d409c7636ca9d607475fcfe8aa4bb3d38dfad706914227efbf. [Узел Figma](https://www.figma.com/design/hskYV8FnfqELPW99dVMHXw/Skaz?node-id=3-3).

Шкала под текущим и максимальным значениями хитов теперь плоская, с цветами темы. Её размер остаётся стабильным. Системный режим высокой контрастности использует стандартную шкалу браузера. Подпись и числа доступны средствами чтения с экрана. Кнопка боя получила капсульную форму и небольшую отметку. Отметка заполняется при начале боя, подпись меняется на «Завершить бой». Размер цели от 44 CSS px.
