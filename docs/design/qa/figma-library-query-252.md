# Актуальная выдача справочника — #252

При вводе Magic Missile прежнее «Опознание» оставалось открываемым до запуска автопоиска. При изменённом запросе справочник сразу показывает состояние ожидания. Старые карточки и навигация по их страницам на это время убраны, поле остаётся в фокусе. [До](figma-library-query-252/before.png) · [После](figma-library-query-252/after.png)

В Edge прошли 18 сочетаний шести размеров и трёх тем. Повторили автопоиск без Enter, пробелы вокруг запроса, ответ прежнего поиска во время правки, чтение новой карточки и возврат фокуса. Очистка поиска вернула недавние карточки. Пробелы не запускали новый запрос. Изменений игры не было. Отдельно воспроизведён тест старой выдачи и позднего ответа.

Сборка, синтаксис, типы игрового экрана и 72 теста справочника прошли. Браузерные проверки авторские. [Приёмка и выпуск](https://github.com/garrimajo5/skaz/issues/252) остаются отдельными.
