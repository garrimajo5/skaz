# Закреплённая широкая шапка СКАЗ

Выпуск `6fadefc` от 27.11.2026, [PR #530](https://github.com/garrimajo5/skaz/pull/530). В [Figma 3:3](https://www.figma.com/design/hskYV8FnfqELPW99dVMHXw/Skaz?node-id=3-3) заголовок и инструменты находятся в одной полосе. Для рабочей прокрутки выбрано закрепление обеих частей вместе, чтобы поиск и меню были доступны, а полоса героя закрывалась всей шириной только по мере прокрутки.

На вымышленной игре в Edge при прокрутке 54 px заголовок раньше уходил на y = −54, а инструменты оставались на y = 0 и накрывали справа полосу героя. На `6fadefc` обе части остались на y = 0 при 1512×982 и 1320×820 во всех трёх темах. Пагинация с клавиатуры ставит результат ниже измеренной шапки, в проверочном случае высотой 136 px. Смена маршрута пересчитывает высоту. При 1319 px и на меньших проверенных размерах инструменты занимают отдельную строку. Пройдено 11 адресных браузерных и 162 общих проверки. В «Быстром доступе» при прокрутке 84 px подтверждены открытие и закрытие меню и запись ячейки с сохранением положения.

[Выпуск 249490c до исправления](wide-header-release-252/before.png) · [Выпуск 6fadefc](wide-header-release-252/after.png). Одинаковая прокрутка и вымышленный герой.

Независимое ревью подтвердило передачу наблюдения между узлами и пересчёт высоты 78 → 136 → 56 px. Linux Node 24, сборка, синтаксис и три проверки типов, 2245/2245.

Свежая копия восстановлена со всеми 48 таблицами. HTTPS, оба входа, cookie, вымышленная игра, экспорт v15, SHA девяти файлов, Origin и выход проверены. Временный доступ и закрытый каталог удалены. Сервис прошёл повторный запуск без временных аккаунтов, публичный запрос вернул 401. Совместимый откат — `249490c`. Android и [физическая приёмка #15](https://github.com/garrimajo5/skaz/issues/15) открыты.

При проверке закреплённого элемента автоматический переход к кнопке может прокрутить страницу. Повтор щелчком в фактической видимой точке подтвердил сохранение прокрутки. Для похожих сценариев стоит проверять реальную прокрутку и нажатие вместе с начальным снимком. Цена один браузерный сценарий, польза в отделении поведения приложения от прокрутки инструмента.
