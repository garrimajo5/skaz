# Общая полоса героя на вкладках

У «Быстрого доступа» и остальных вкладок уже был общий шаблон данных героя. Расходились компоновка и стили. Например, при 1920×1080 блок хитов начинался на x=681 в «Быстром доступе» и на x=930 в «Персонаже», высота содержимого была 104 и 86 CSS px.

Обе компоновки используют общий контейнер и одинаковые стили. В широком окне соседняя область отведена для игровых кнопок. В компактном окне эти кнопки вынесены под полосу. На «Карте» сводки и боевых ресурсов нет по решению владельца.

При одинаковом размере окна сравниваются размеры полосы, позиции её пяти областей относительно полосы, видимость подписи и подкласса и шрифт числовых значений. Отдельно проверяются вход и выход из боя и список призывов. В обзоре PR приводится число проверенных сочетаний.
