## Рефлексия

На первом проходе измерили положение элементов. Независимый проверяющий показал, что этого было недостаточно для двух кнопок, которые отключаются при сохранении. В проверку добавили переходы «ожидание → доступ разрешён» и «ожидание → доступ запрещён» для сохраняемых кнопок. При следующих правках постоянных элементов стоит испытать этот тест сразу. Цена один целевой сценарий, польза в выявлении сломанной кнопки до выпуска.
