# QA #46 — ячейки, история и ручное превышение

Выпуск `6a09875`, вымышленный герой Мирен Таль. Три размера Edge с вводом касанием, 320×780 «Атлас», 820×1180 «Полярис» и 1180×820 «Уголь». [Предыдущий портретный прогон Pixel_8](https://github.com/garrimajo5/skaz/issues/46#issuecomment-7131553261) подтвердил две отдельные команды на прямых касаниях.

| Критерий | Результат |
| --- | --- |
| Потратить и вернуть касанием | Заполненная ячейка 1-го круга дала 3 → 2, пустая 2 → 3. Каждое касание увеличило ревизию на одну. В ряду ровно четыре кнопки ячеек, без отдельной отмены. |
| История и адресная отмена | Две записи 3 → 2 и 2 → 3 содержат доступную отмену. Enter в истории на последней вернул остаток 3 → 2, повторная отмена этой записи стала недоступна. |
| Состояние читается без цвета | Сплошная заливка и прозрачное кольцо различаются. Метки 26×26 CSS px на 320 и 820, 31×8 в правом пульте 1180 в компоновке [#252](../quick-access-252.md). Цели во всех проверенных размерах 44×44 CSS px. Кнопки озвучивают действие. [Монохромный ряд](resource-pips-46/gray.png). |
| Ожидание сервера | В альбомном Edge отказ отправки оставил одну команду в очереди, метка имеет имя «Ждёт подтверждения сервера». После «Отправить очередь» остаток изменился один раз и метка исчезла. |
| Сверхлимитный ручной результат | «Ресурсы класса» → «Изменить» → «Осталось 3» при максимуме 2 → «Проверить лист». Предупреждение 3 и диапазон 0–2 видны, сохранение работает с пустой отметкой. [Форма предупреждения](resource-pips-46/warning.png). |
| Согласование и изменение условий | При повторной проверке 3/2 сохранены отметка и пояснение. После перезагрузки отметка свернута. Перенос v15 и отдельная правка характеристик сохраняют счётчик и пояснение. При изменении на 4/2 предупреждение снова раскрыто, прежняя отметка снята, значение сохраняется. |
| Техническая защита | 28/28 в `resource-operations`, `resource-queue`, `profile-recovery-http` и `profile-recovery-package`. Покрыты права, конфликт, очередь, точный повтор и адресная отмена. |

Числа относятся к вымышленному листу и указанным размера́м. Панель физического Xiaomi в двухчасовой сессии проверяется в M2 отдельно. Браузер, RAM-стенд и собственные Android-ресурсы закрыты.

Рефлексия QA. Проверка касаний отдельно от снимка монохрома сразу сохранила полезные результаты при тайм-ауте захвата. Полезно держать эти три утверждения отдельными в дальнейших сценариях пульта.
