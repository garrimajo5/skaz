# Целые слова на карточках «Быстрого доступа»

Кандидат `6e53e42`, [PR #463](https://github.com/garrimajo5/skaz/pull/463) · [#252](https://github.com/garrimajo5/skaz/issues/252) · [макет Figma 3:3](https://www.figma.com/design/hskYV8FnfqELPW99dVMHXw/Skaz?node-id=3-3).

## Android Chrome

На Pixel_8 при ширине 411 CSS px и удвоенном через стенд тексте слова в названии ручного заклинания разрывались рядом с кнопкой. При нуле ячеек касание всё же открыло форму. «Записать без расхода» без отметки мастера добавило ровно одну запись, ревизия 10 → 11. Третий круг остался 0, хиты — 18.

После переноса кнопки название помещается целыми словами, форма открывается тем же касанием. Касание названия зелья на свежем стенде открыло описание при неизменных ревизии 10 и количестве 2. Последние поправки типографики и самого узкого переноса проверены в Edge. Системный масштаб не меняли. Свои вкладки закрыли через меню Chrome, проброс сняли.

## Edge

На трёх темах, 66 размерах и обычном и удвоенном тексте проверены 3168 карточек. Использовалась вымышленная игра, включая длинную подпись с отметкой мастера. Горизонтальной прокрутки, выходящих кнопок и разрывов слов в проверенных карточках нет. Для одиночного слова длиннее всей доступной области сохранён запасной перенос.

В сравнительных прогонах разрывы внутри названий заклинаний сократились с 807 до 0, у расходников с 291 до 0, внутри подписей команд с 108 до 0. Обычная геометрия заклинаний и ширина цены сохранились. Шрифт имени расходника остался 14 px и в цвете текста темы, остаток сохранил свой стиль. Две широкие карточки остались 64 px. Девять обычных компактных случаев с уже разорванными словами стали выше максимум на 42 px, остальные обычные высоты совпали.

[Расходник до](figma-word-wrap-252/item-before.png) · [после](figma-word-wrap-252/item-after.png) · [Широкая команда до](figma-word-wrap-252/command-before.png) · [после](figma-word-wrap-252/command-after.png).

После чтения Escape вернул фокус. Переход Tab и Enter списал одно зелье, отмена в инвентаре дала 2 → 1 → 2. Выбор второго круга дал 2 → 1, первый круг и хиты сохранились. После перезагрузки сохранилась ревизия 15. При недоступном PNG чтение открылось на 320, 411 и 1512 px без записи. Касание нижнего края «Указать заряды» открыло пустое поле неизвестного остатка на 320 px. Поворот окна сохранил форму, Escape вернул фокус без изменения ревизии.

В 240 подстановках длинных названий из встроенного каталога текст остался внутри карточек. В 15 случаях сработал запасной перенос для слова, превышающего доступную ширину. Подстановки меняли только тестовую разметку.

SHA-256 архива `6e53e42` — `706099d6ed759ceefed1be8ff99afdecd3faed2e952196801d666f2dfa585401`. Исходники прошли отдельное read-only ревью, включая исправление исходной типографики.
