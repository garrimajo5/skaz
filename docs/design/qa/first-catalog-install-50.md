# QA #50 — первый запуск справочника

Воспроизведение от `5bd6139` на отдельных вымышленных RAM-играх. Снимок состояния игры до и после установки совпал целиком.

| Сценарий | Проверка |
| --- | --- |
| Справочник, Полярис, Edge 1180×820 | Открыть «Заклинания», ввести запрос без совпадений. До установки видна подсказка. Одно касание открывает предпросмотр. После установки тот же запрос даёт «Ничего не найдено», а «Огненный шар» находится. |
| Магия, Уголь, Edge 820×1180 | Одно касание открывает предпросмотр. Escape закрывает его без записи. Enter открывает снова. |
| Вещи, Атлас, Edge 390×844 | Одно касание открывает предпросмотр. После записи намеренно повреждён ответ. Повтор отправляет ту же версию, итог остаётся 633 карточки без дублей. |
| Индивидуальный вход, Edge 820×1180 | Серверному игроку и владельцу кампании на трёх экранах сразу показано, что подборку устанавливает администратор. Прямые предпросмотр и установка дают 403, подборка остаётся пустой. |
| Chrome Pixel_8, портрет | Из «Вещей» одно касание открыло предпросмотр. Второе, подтверждающее, установило 633 записи. В отдельной вымышленной игре серверного игрока показана администраторская подсказка. Открытие справочника касанием доступно, записей по-прежнему 0. |

Предпросмотр считает текущий состав. В проверенном комплекте 319 заклинаний, 204 существа, 56 предметов, 1 артефакт и 53 механики. Предпросмотр требует только чтения. После подтверждения и обновления подсказка пустой базы исчезает. Физический Xiaomi Pad 6 этим прогоном не проверялся.

`node --test tests/catalog-client.test.mjs tests/bundled-catalog.test.mjs tests/access.test.mjs` — 106/106. Новая проверка покрывает все три места вывода одной пустой подсказки. Свои вкладки, сервер и проброс 4337 закрыты. Настройки Android в прогоне не менялись.

Рефлексия. Проверка только в локальном режиме пропускала кнопку без доступного действия при индивидуальном входе. Для пустых состояний общего каталога стоит проверять в паре локальный режим и подтверждённый серверный запрет. Цена — один небольшой изолированный сценарий, результат — верное действие ещё до клика.
