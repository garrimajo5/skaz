# Результаты текущего запроса — #252

В поиске «Быстрого доступа» после замены Identify на Magic Missile оставалась активной карточка «Опознание». Теперь старый список убирается при правке запроса. Поле остаётся в фокусе, поиск запускается через «Найти». [До](figma-search-current-results-252/before.png) · [После](figma-search-current-results-252/after.png)

В Edge на шести размерах от 320 × 568 до 1512 × 982 проверили правку запроса, очистку поля, пробелы, повторную отправку и возврат из карточки с фокусом на строке. После задержанного Identify новый запрос успел найти Magic Missile. Поздний ответ сохранил новый список. На правку текста и возврат из карточки новых запросов не было. Игровых записей не было.

Поведенческий тест покрывает правку после ответа, пустое поле, невернувшийся запрос и новый результат. Сборка и проверка типов игрового экрана прошли. Браузерные проверки авторские. [Независимая приёмка и выпуск](https://github.com/garrimajo5/skaz/issues/252) учитываются отдельно.
