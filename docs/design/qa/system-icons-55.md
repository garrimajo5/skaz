# Остаток системных значков — #55

24.11.2026. В исходном runtime `bf92f07` навигация и клавиша стирания уже
использовали общий SVG. В Edge клавиша «Удалить последнюю цифру» действительно
удалила 9 из 29; её внутренний идентификатор `⌫` на экране не отображается.

При проверке оставались стрелки и добавление в кнопках профиля, книги,
справочника, инвентаря и карты, текстовый знак раскрытия в строке, а также точки
в индикаторе очереди, владении и результатах спасбросков от смерти.

## Что изменилось

| Сценарий | Представление |
| --- | --- |
| Переход, назад, внешний источник, добавление, продолжение и пауза примера | SVG из существующего локального sprite. У каждого действия сохраняется текст или доступная подпись. |
| Раскрытие описания в инвентаре | Локальный SVG поворачивается вместе с состоянием native details. Enter раскрывает и сворачивает строку. |
| Урон до 0, затем один успех | На пульте «Успехи: 1/3 · Провалы: 0/3», доступное имя содержит действие и оба итоговых числа. |
| Владение спасброском | Декоративная SVG-отметка и отдельный текст для чтения с экрана. Правило и бонус прежние. |
| Очередь без ответа | SVG и отдельный числовой счётчик. Обновление числа сохраняет элемент со значком. |
| Метка выбранной позиции на карте | Локальный SVG. Текущая клавиатурная правка координат остаётся на подписанных ползунках. |

Аудит строк и CSS охватил код приложения. `before → after`, числовые знаки,
умножение, сокращения кругов и знаки правил продолжают передавать значение.
Источник шрифтовых значков перечисленных элементов удалён. Графика не
создаёт сетевых запросов. Доступность физического планшета проверяется отдельно.

28 герой остался при 0/38, одно касание кнопки успеха привело к 1/3.
