# QA #44 — прямые ссылки и книга «Магия»

На выпущенном `c5a5a13` новое открытие `#library` в той же вкладке после «Быстрого доступа» возвращало на `#play`. Книга отсылала к пункту «Игра», у которого уже была новая подпись. [Снимок до](navigation-intent-44/book-before.png).

| Критерий | Проверка в Edge |
| --- | --- |
| Переход открывает запрошенный раздел | «Быстрый доступ» → «Магия» → «Вещи» → «Справочник» с возвратами. После «Быстрого доступа» новые загрузки с `#library` и `#spells` открывают указанный раздел. Адрес без раздела сохраняет запомненный экран. |
| У игрового экрана одно имя | В боковой и нижней навигации — «Быстрый доступ». Переключатель «Игра / Подготовка» отсутствует. |
| В книге видно, где сотворить заклинание | Книга и её карточка «Огненный шар» позволяют читать. Рядом с заголовком подчеркивается ссылка «Быстрый доступ». Enter открывает игровой экран с кнопкой сотворения. [Снимок после](navigation-intent-44/book-after.png). |

Вымышленная кампания, 390×844 «Атлас», 820×1180 «Полярис» и 1180×820 «Уголь», включён ввод касанием. Регрессионный тест ожидаемо упал до правки с `play !== journal`. После правки 142 теста по форме, игре, книге и справочнику прошли. Физическая приёмка планшета остаётся в M2.

Рефлексия frontend и QA. Обычные переходы с уже загруженной страницы пропустили дефект. Для следующей правки маршрутов проверять открытие прямого адреса из новой загрузки при имеющемся значении в `sessionStorage`.
