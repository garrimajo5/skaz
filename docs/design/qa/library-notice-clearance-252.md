# Поиск справочника рядом с всплывающим уведомлением

[Задача #252](https://github.com/garrimajo5/skaz/issues/252) · [Правило стабильной компоновки](../visual-guidelines.md).

В альбомном окне 844×390 подтверждение ячейки перекрывало 14 254,25 CSS px² поля поиска при 24 px. Справочник использует общий расчёт свободного места. Он учитывает видимые поля, кнопки и переключатели фильтров. При раскрытии фильтров пересчитывается положение сообщения.

В Edge проверены 18 сочетаний размера, темы и формы с задержанным ответом. Перекрытие поля исчезло, геометрия, фокус, прокрутка и черновик не изменились. Кнопка «Отменить» доступна, за расходом следует один запрос отмены. Ещё шесть проходов открытия фильтров при активном сообщении в обеих ориентациях телефона. 133 целевых теста.
