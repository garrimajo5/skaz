# Возврат к строке инвентаря · #252

После добавления предмета из справочника инвентарь открывается в диалоге. «Читать» показывает сохранённый предмет. При нажатии «К инвентарю» снова видна его строка и фокус возвращается на «Читать». При повторной загрузке предмет ищется по ID каталога. Сохраняется положение списка, в том числе после возврата через справку или учёт зарядов.

[До](modal-inventory-return-252/before.png) · [После](modal-inventory-return-252/after.png). Edge, Уголь, 700 × 212. В исходной версии прокрутка сбрасывалась с 262 px до 0, кнопка теряла фокус. После изменения сохраняются 262 px и фокус на «Читать».

## Проверки

- Edge: пять размеров от 700 × 212 до 1180 × 820, Полярис, Уголь и Атлас. До изменения 15/15 возвратов теряли фокус или положение, после исправления 15/15 восстановили их.
- Ещё 15 возвратов с HTTP 503 при загрузке списка прошли с использованием имеющегося кэша. Чтение и возврат не меняют хиты, ячейки, ревизию и количество вещей.
- Регрессионный тест меняет порядок ответа и проверяет возврат после ошибки без кэша. Старое действие не переводит фокус на строку при смене контекста.
- На Pixel_8 в Chrome проверены возвраты из справочника и учёта зарядов к сохранённому Посоху огня. Возврат к строке списка в диалоге проверен в Edge. Физический Xiaomi и рабочий выпуск остаются отдельными шагами.
