# Карточки справочника во время игры

26.11.2026 МСК. [Редизайн #252](https://github.com/garrimajo5/skaz/issues/252)
и [макет Figma 3:3](https://www.figma.com/design/hskYV8FnfqELPW99dVMHXw/Skaz?node-id=3-3).
Итоговый код `91edf50fcb4184ea3255b37b06aa67f27ad8a32f`.
Карточка использует боковую панель, токены и иллюстрации приложения.
Компактная раскладка распространяется на чтение из «Игры» и поиск
внутри неё. Для первых и остальных характеристик предусмотрены
одни и те же значения карточки.

## Chrome на Pixel_8

На точном `abb8132` из #438 открыли поиск на вымышленной игре.
Уголь, 2280 × 960, density 480. До прокрутки видны первые значения
[заклинания](figma-game-card-reader-252/pixel-spell.png),
[существа](figma-game-card-reader-252/pixel-monster.png) и
[предмета](figma-game-card-reader-252/pixel-item.png).
Из карточки заклинания перешли к описанию. Из карточки гоблина
вернулись к запросу и результату. Свою вкладку закрыли, размер
1080 × 2400, density 420, auto 1, rotation 0 и HOME восстановили.
Проброс 4337 удалён. Обновления #439–#442 проверяли в Edge.

## Итоговый прогон

В Windows Node v26.13.0 дерево кода совпало с итоговым main. Из
2 217 тестов прошли 2 211, 6 пропущены по условиям платформы, ошибок 0.
В Edge на итоговом коде проверен обычный справочник: действия карточки
доступны. При повторном открытии поиска задержанный ответ старого
запроса не появился, запросов записи не было.

SHA-256 архива из Git для `91edf50`
`e33bcd64ceb5e0087065d041a50431603fca20c313f587a5fd39de7e9eedb243`.
Проверка имён внутри архива не нашла SQLite, ключей, аудио и закрытых `.env`.

В отдельном Linux-контейнере Node v24.22.3 прошли проверка синтаксиса,
три проверки типов, сборка и тесты. Из 2 217 тестов прошли 2 214,
3 пропущены по условиям платформы, ошибок 0.

Пять PR прошли отдельное ревью. Использовались темы Полярис, Уголь и
Атлас. Локальный стенд остановлен, порт 4337 освобождён.

убедиться, что та же строка видна и сохраняет фокус.
