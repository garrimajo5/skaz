# Подпись игровой навигации в обеих ориентациях

В выпуске `4f092b8` один и тот же маршрут `#play` подписан «Игра» снизу и «Быстрый доступ» слева. Нижний пункт теперь использует название из редизайна. Маршрут, значок, переключение пульта и порядок вкладок сохранены. [Редизайн #252](../quick-access-252.md).

| Проверка кандидата в Edge | Результат |
| --- | --- |
| 820×1180, «Быстрый доступ» и «Вещи» | Навигация и пульт доступны снизу. Панели 64 + 150 = 214 CSS px из допустимых 220. Подпись занимает одну строку. |
| 1180×820, оба экрана | Навигация слева доступна, подпись совпадает с портретной. Текст «Справочник» одинаковый. Широкая версия также показывает дополнительные пункты «Персонаж» и «Карта». |
| 320×780 и 390×844, оба экрана | Полная подпись помещается в две строки. На 320 px цель нового пункта 48×55 CSS px, все видимые соседние цели не меньше 44×55. На 390 px минимум 52×55. Горизонтальной прокрутки документа нет. |
| Полярис, Уголь, Атлас | 24 сочетания экрана, размера и темы. Касание ведёт из игры в инвентарь, Enter открывает журнал из инвентаря. Активное состояние совпадает с адресом. |

[До, 820×1180](cantrip-badge-41/polar.png) · [После, 820×1180](tablet-navigation-42/after-tablet.png) · [После, 320×780](tablet-navigation-42/after-phone.png).

Pixel_8 до изменения открыл портретную вымышленную игру с нижней навигацией. Во время перехода устройство занял другой прогон. Дальнейшие касания и поворот остановлены. Свой проброс и сервер освобождены, настройки не менялись. Обе ориентации кандидата проверены в Edge, Android после правки и физический Xiaomi остаются отдельными результатами.

Рефлексия frontend. Проверка только новой кнопки пропустила бы уменьшение соседних целей. Быстрый замер всех кнопок в ширине 320 px сохранил 44 px и выявил перенос подписи на три строки при 10,5 px. Для следующих правок нижней панели полезно проверять всю строку по координатам вместе с касанием.
