# Три первых кандидата на стиль — 08.11.2026

Созданы встроенным image_gen по явному разрешению пользователя в этом чате.
Отдельный API, платный сервис, чужие изображения и подагенты не использовались.
Это 3 кандидата из пилота на 24 изображения, не принятые production-ассеты.

| Образец | Размер | Исходный PNG |
| --- | --- | --- |
| Огненный снаряд | 1254×1254 RGBA | 525255 байт |
| Зелье лечения | 1254×1254 RGBA | 1242931 байт |
| Гоблин | 1254×1254 RGB | 2225405 байт |

Оригиналы сохранены без изменений в игнорируемой `data/art-pilot-v1/`.
Их дубликаты генератора остаются в локальном каталоге Codex. SHA256,
точные ID и contentSha256 каталога — в candidates.json. Оригиналы пока не
коммитятся: по art-registry.md промежуточные генерации не входят в Git.
Свежий checkout без этих локальных файлов НЕ воспроизводит картинки.

Локальный просмотр: `node scripts/art-pilot-server.mjs`, затем
http://127.0.0.1:4188/. Сервер слушает только loopback и отдаёт явный список
трёх картинок, страницу и шрифты; не открывает игру/SQLite/учётные данные.
Остановить Ctrl+C после просмотра. index.html — стенд, не игровые карточки.

## Художественные решения

- Огонь: один направленный силуэт, тёмно-оранжевый край и светлое ядро,
  без круглого взрыва. Миниатюра читается на трёх темах и без цвета.
- Зелье: простой узнаваемый флакон, гранёная пробка, рубиновая жидкость;
  детали кожи не нужны для узнавания. Следующие зелья должны отличаться формой.
- Гоблин: охристая кожа, настороженное лицо, спокойный серый фон. Круглый
  жетон использует CSS contain с дополнительным полем 12%, чтобы не срезать
  уши. Для будущих портретов просить более щедрое исходное поле.

Это художественные интерпретации, не новые характеристики D&D и не копии
официальных иллюстраций. Проверка трёх разных семейств не доказывает
различимость похожих заклинаний/видов — для этого нужны остальные 21 образец.

## Проверки и ограничения

Браузер: все три темы рядом; 32/48/64 px, крупный вид и круглый жетон;
переключатель grayscale. 1180×820, 820×1180, 390×844. Найдено сжатие образцов
в портретных колонках: исправлено переносом тем в одну колонку до 950 px,
запретом flex-shrink у образцов и переносом ряда. После исправления фактические
ширины 32/48/64 совпали, горизонтального переполнения страницы нет.
Контактные листы и снимок телефона — локально data/art-pilot-*.png.
Повторный fullPage-снимок после исправления дал ошибку захвата; первый
альбомный контактный лист сохранён, раскладка альбомного размера не менялась.
Проверка эмулятором/настоящим планшетом в этом блоке не заявляется.

Производственный inspectPng отклонил все три оригинала из-за блока caBX.
Проверка не ослаблялась и блок не удалялся; исходные файлы сохранены.
Перед включением в реестр нужен отдельный воспроизводимый процесс подготовки
доставляемых файлов с сохранением исходного происхождения. Картинки браузер
декодирует, но это не означает прохождение строгой приёмки реестра.
Общий вес 3993591 байт (~3.81 MiB): это тяжёлые исходники, не бюджет игровой
загрузки. Миниатюры пока CSS-масштабирование оригиналов, не отдельные файлы.
