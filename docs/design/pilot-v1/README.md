## Художественные решения

- Огонь: один направленный силуэт, тёмно-оранжевый край и светлое ядро,
  без круглого взрыва. Миниатюра читается на трёх темах и без цвета.
- Зелье: простой узнаваемый флакон, гранёная пробка, рубиновая жидкость;
  детали кожи не нужны для узнавания. Следующие зелья должны отличаться формой.
- Гоблин: охристая кожа, настороженное лицо, спокойный серый фон. Круглый
  жетон использует CSS contain с дополнительным полем 12%, чтобы не срезать
  уши. Для будущих портретов просить более щедрое исходное поле.

Это художественные интерпретации, не новые характеристики D&D и не копии
официальных иллюстраций. Проверка трёх разных семейств не доказывает
различимость похожих заклинаний/видов — для этого нужны остальные 21 образец.
