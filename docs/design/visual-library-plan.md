Все задачи имеют критерии готовности. Следующее действие: реальный игровой
просмотр пилота #33/#34, продолжение аудита #31; не начинать сотни генераций
до приёмки визуального языка. По просьбе пользователя автоматизация claude
возобновлена ежечасно 09.11, без дублирования расписания.

Порядок: аудит палитры и реестр → пилот 24 изображений и решение по стилю →
подключение библиотеки → полное производство трёх семейств → итоговая приёмка.
Личные замены можно реализовывать после определения реестра и модели доступа.
Подагенты и платные AI-вызовы не разрешены. Массовое производство ждёт решения
по пилоту; независимые программные задачи доступны.

Закрытие сводки требует принятого изображения у каждого актуального ID
заклинания/предмета/артефакта/существа, прав использования и программной приёмки.
Заглушки не считаются покрытием. Физические проверки остаются в старой очереди.
