# Первый аудит палитры, 08.11.2026

Часть #31, НЕ полная приёмка интерфейса. Изолированная страница использует
реальные client/style.css и quick.css, getComputedStyle, разрешение CSS-цвета
через canvas и sRGB-расчёт контраста с композицией собственной opacity.
Три темы × 13 образцов = 39 измерений. Исходные значения:
[до](theme-audit-baseline.json), [после](theme-audit-after.json).

Воспроизведение из корня: `node scripts/theme-audit-server.mjs`, открыть
http://127.0.0.1:4187/, переключить три темы; JSON доступен под таблицей.
Сервер слушает только loopback и отдаёт только fixture, CSS/JS и локальные шрифты.
Остановить Ctrl+C после проверки. Он не открывает БД и данные кампаний.

Исправление: непрозрачные disabled-кнопки, вторичный текст на поднятой
поверхности, пунктирная рамка, без hover-подсветки/перемещения. Нативный
disabled остаётся: оформление не разрешает нажатие. Палитра тем не изменена.
После исправления все 39 образцов проходят цели 4.5:1 для текста / 3:1
для акцента фокуса на панели. Эти цели относятся к нашему дизайн-гайду,
не являются заявлением о сертификации доступности всего приложения.

Проверена заполненная вымышленная игра: расход последней ячейки показал
читаемые «нет ячеек 1+/2+/3+», кнопки действительно disabled; возврат
ячейки восстановил доступность. Режим подготовки и исходный остаток восстановлены.
