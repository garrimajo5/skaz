# Один вымышленный пример официальной компоновки — #80

Статус: локальный исследовательский корпус M0, не готовое распознавание. [Метаданные и ожидаемые значения](official-sheet-sample-80.json), [пустая первичная форма](official-sheet-layout-80.json), [игровая сверка](../sheet-recognition-game-review-80.md).

## Воспроизведение

Нужен точный публичный [пустой WotC PDF](https://media.wizards.com/2016/dnd/downloads/5E_CharacterSheet_Fillable.pdf), SHA из manifest, pypdf6.21.4, Pillow и Poppler26.07.0. Генератор не скачивает файлы, не читает произвольный личный лист и не обращается к API. Перед разбором проверяет исходный SHA; путь результата должен быть новой папкой.

```sh
python scripts/build-official-sheet-sample-80.py <public-blank.pdf> <new-local-folder> --render
```

Результаты только локально: интерактивный PDF, три PNG200dpi и sample-manifest.json. Сам PDF и растры не включены в Git: условия перепубликации шаблона не установлены. В Git находятся код, метаданные, ожидаемые значения и тесты. Не добавлять исходники/производные в коммит автоматически. Для OCR это **два альтернативных входа одного случая**: один PDF из3страниц либо три PNG; не6различныхстраниц.

## Что подтверждено автором

- PDF612987байт,3страницы,334именованных поля/336widgets; интерактивность сохранена, Parent/Kids не ремонтировались. Все выбранные14канонических значений совпадают с widgets и имеют непустой appearance. Имена, типы и незаполнявшиеся значения остальных полей сохранены.
- Все три растровые страницы просмотрены: LyraQA, Wizard3/Warlock2, DEX14, maxHP27/пустойcurrent/temp0, страница заклинаний Wizard/INT/DC13/+5, MageHand в строке заговора, слот1круга total4/expended1 видимы без обрезки. Это частичный вымышленный лист, не полный игровой профиль.
- Два построения PDF совпали побайтно; после добавления рендеринга повторились PDF и все3PNG. SHA/размеры/dpi и связь derivedFromPdfSha256 закреплены. Версии генераторов записаны; другая версия инструмента не обязана дать те же байты.
- Три новых Python-проверки: запрет перезаписи папки, отказ чужого PDF до создания результата, отсутствие канонического значения нельзя засчитать по appearance. Вместе с аудитом9/9. Три Node-проверки закрепляют SHA генераторов, происхождение/альтернативные входы и разделение printed/derived/unreviewed.

## Что нельзя заключать

Общий уровень5 не напечатан отдельным полем: это кандидат из3+2. На странице Wizard нет данных PactMagic: не выводить их по уровню колдуна. Остаток3 также не напечатан: это кандидат из4−1. chosenRemaining=null и selectionStatus=unreviewed сохраняют отсутствие подтверждения. ПустоеcurrentHP=null отличается отtemp0. MageHand — исходная строка без автоматически назначенного catalogId.

Один чистый английский образец не доказывает точность OCR, качество фото, поддержку всех русских/английских форм, сохранение в приложении или репрезентативность всего корпуса. Действующих импортных API, автоматического заполнения настоящего профиля и выпуска нет. #80/M0 не закрываются, #84/#97 не становятся Ready; nullable-интеграция #81/#82 остаётся.

Следующий шаг: независимая сверка этого артефакта по всем3страницам и полям; затем ещё одна согласованная реальная компоновка с вымышленными значениями/качеством снимка, отдельное подтверждение схемы nullable. Личный Эдвин/LSS не используется.
