# Темы интерфейса

Решение: Полярис — тема по умолчанию. Уголь и Атлас сохраняются как полноценные варианты.

| ID | Название | Характер |
| --- | --- | --- |
| `polar` | Полярис | Тёмно-синий фон, мятный акцент, современная типографика |
| `coal` | Уголь | Графит, тёплое золото, литературные заголовки |
| `atlas` | Атлас | Светлая бумага, лесная зелень, картографическая атмосфера |

Тема задаётся `data-theme` на `body`. Цвета компонентов используют семантические CSS-переменные: `--bg`, `--panel`, `--raised`, `--line`, `--text`, `--muted`, `--accent`, `--ink`, `--green`, `--red`, `--wash`.

Новые компоненты должны использовать эти переменные. Нельзя привязывать смысл действия только к цвету. При изменении компонента проверяются все три темы: обычное состояние, фокус, отключённая кнопка и длинные русские подписи.

Выбор пользователя хранится в настройках этого браузера отдельно от кампании. Сохранённая тема имеет приоритет над темой по умолчанию; неизвестный ID заменяется на `polar`.

`concepts.png` — художественная иллюстрация направлений, созданная генератором изображений. Источник истины для механик и взаимодействий — работающий интерфейс, а не текст на концепт-арте. Запрос генерации сохранён в `concept-prompt.txt`.

## Игровые элементы, ноябрь 2026

Полярис — тема по умолчанию. Уголь и Атлас выбираются в «Данные и настройки».
Настройка сохраняется в браузере, не меняет кампанию или ресурсы.

| Назначение | Переменная / правило |
| --- | --- |
| Фон, карточка, поднятая поверхность | --bg, --panel, --raised |
| Основной и вторичный текст | --text, --muted |
| Акцент, текст на акценте | --accent, --ink |
| Ошибка / опасность | --red + текст причины |
| Предупреждение | --warn + текст состояния |
| Обычная зона нажатия | --touch: 44px |
| Изменение ресурса | --resource-touch: 48px |
| Служебный текст | --ui-small: 12px |
| Основной текст | --ui-body: 16px (целевой токен, внедрение ещё не полное) |
| Противоположные действия | промежуток 16px |

Числа хитов выводятся табличными цифрами. Включён prefers-reduced-motion.
Высота нижних панелей измеряется ResizeObserver; контент и уведомление получают
соответствующий отступ, включая переносы и safe-area. Без ResizeObserver есть
консервативный CSS-отступ. Диалог числа открывается снизу, без автофокуса ввода.

В Атласе вторичный текст затемнён до #52665b, предупреждение до #805916.
Полный аудит контраста всех сочетаний/состояний и физического iPad пока не выполнен;
этот документ не является подтверждением соответствия WCAG всего приложения.

## Проверяемые токены и автоматический аудит (08.11.2026)

`--ok: var(--green)` и `--danger: var(--red)` — семантические имена состояний;
`--warn` — ожидание/конфликт, всегда вместе с подписью и числом действий.
Все темы наследуют размерные токены: `--touch:44px`, `--resource-touch:48px`,
`--ui-small:12px`, `--ui-secondary:14px`, `--ui-body:16px`, `--ui-number:28px`,
`--ui-hp:52px`. Точки ресурсов имеют область 44 px; кнопки изменения здоровья,
завершения концентрации и списания расходника — 48 px. Между уроном и лечением
16 px. Цифры хитов, модификаторов и игрового списка табличные. Карточки правил
и записи журнала используют основной текст 16 px. Декоративной анимации в
игровом экране нет; прежнее правило reduced-motion отключает переходы.

Палитра проверяется `node --test --test-isolation=none tests/design-tokens.test.mjs`.
Проверяем --text/--muted/--accent/--green/--red/--warn на --bg/--panel/--raised
и --ink на --accent. Нижние отношения основной матрицы: Уголь 6.23:1,
Атлас 4.58:1, Полярис 5.97:1; все ≥4.5. Не выдаём это за сертификацию WCAG
всего приложения: прозрачность отключённых элементов, изображения, сторонние
шрифты и пользовательские условия требуют отдельной оценки.

`scripts/audit-game-ui.mjs` экспортирует read-only `auditGameUI()` для выполнения
в отрисованной странице браузера. Он возвращает нарушения шрифта <12 px и
кнопок/summary <44×44 px; не учитывает скрытые элементы и содержимое закрытых
details, не читает localStorage или данные приложения. При разработке функцию
выполняем через разрешённый браузерный инструмент и проверяем пустые fonts/buttons.

Проверены герой, магия, инвентарь и игра × три темы × размеры 1180×820,
1024×768, 820×1180: 36 сочетаний без нарушений (ещё 4 начальные контрольные
проверки также прошли). Локальное свидетельство data/game-ui-audit.json
игнорируется Git. Это автоматическое измерение браузера, не реальный iPad.
