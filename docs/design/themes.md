# Темы интерфейса

Решение: Полярис — тема по умолчанию. Уголь и Атлас сохраняются как полноценные варианты.

| ID | Название | Характер |
| --- | --- | --- |
| `polar` | Полярис | Тёмно-синий фон, мятный акцент, современная типографика |
| `coal` | Уголь | Графит, тёплое золото, литературные заголовки |
| `atlas` | Атлас | Светлая бумага, лесная зелень, картографическая атмосфера |

Тема задаётся `data-theme` на `body`. Цвета компонентов используют семантические CSS-переменные: `--bg`, `--panel`, `--raised`, `--line`, `--text`, `--muted`, `--accent`, `--ink`, `--green`, `--red`, `--wash`.

Новые компоненты должны использовать эти переменные. Нельзя привязывать смысл действия только к цвету. При изменении компонента проверяются все три темы: обычное состояние, фокус, отключённая кнопка и длинные русские подписи.

Выбор пользователя хранится вместе с демонстрационным состоянием. Сохранённая тема имеет приоритет над темой по умолчанию; неизвестный ID заменяется на `polar`.

`concepts.png` — художественная иллюстрация направлений, созданная генератором изображений. Источник истины для механик и взаимодействий — работающий интерфейс, а не текст на концепт-арте. Запрос генерации сохранён в `concept-prompt.txt`.
