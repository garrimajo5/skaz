# Прототип карточек заклинаний — 17.11.2026

Refs #34. Роли: UX → frontend, авторская проверка; независимая приёмка впереди.
По запросу владельца создан первый работающий вариант в существующем справочнике.
Карточки/список переключаются без загрузки данных, потери запроса или изменения героя.
В карточке: библиотечный арт, RU/EN, круг/школа, время, дистанция, длительность,
компоненты, концентрация/ритуал. Краткий эффект только из проверенного SkazSpellFacts,
без уровня героя; неподдержанные записи не получают выдуманную формулу.
Полный текст не обещается: ссылка называется «Описание и правила».

## Осталось до выпуска

Это первый прототип заклинаний, не выпуск всей системы карточек.
Монстры и предметы пока используют прежний вид. Следующий шаг — оценка владельцем
плотности/размера арта, затем отдельные карточки существ и категорий предметов.
Не выполнены Android/физический Xiaomi, независимые QA и игровой обзор,
полный регрессионный прогон и выпуск. Метки состояния героя, дорогие/расходуемые
материальные компоненты и полная матрица длинных/неполных записей ещё нужны.
Крупный арт использует существующие card-файлы; новые сетевые бюджеты не измерены.

Рефлексия: старый quick.css перекрывал сетку и отступы. Исправлено ограниченной
специфичностью только справочника. Предложение планировщику: перед расширением
на остальные типы принять плотность этого прототипа; общие правила не менялись.
