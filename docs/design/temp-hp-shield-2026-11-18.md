# Щит временных хитов — #31

Декоративный локальный SVG рядом с числом и подписью обозначает отдельный запас временных хитов. Доступное имя здоровья включает временные хиты; при нуле щит и подпись отсутствуют. Расчёты ресурсов не меняются.

Сохранённые браузерные проверки предыдущего блока: три темы, выдача7 временных хитов, перезагрузка, поглощение7 урона при обычных28 хитах, отмена с восстановлением7. Снимки: [Полярис](qa/temp-hp-shield-2026-11-18/temp-shield-polar-tablet.jpg), [Уголь](qa/temp-hp-shield-2026-11-18/temp-shield-coal-phone.jpg), [Атлас](qa/temp-hp-shield-2026-11-18/temp-shield-atlas-tablet.jpg). До изменения подпись +N уже существовала, щита не было — видно в diff healthVitals.

18 ноября при завершении сохранённой работы повторно выполнены32 теста app-form-guards:32pass. Сохранённый полный Windows-прогон этой рабочей копии:1331pass/0fail/6skip; это не полный тест актуального main после интеграции. Android именно щита и независимая приёмка остаются; выпуск не выполнен. Нужны интеграционные проверки после объединения с main.

Рефлексия: незакоммиченный маленький этап потерялся между задачами. Предложение планировщику — перед переключением фиксировать проверенный этап отдельным коммитом с явным остатком; польза — проще продолжать, затраты малы, риск — коммит не должен означать приёмку. Решение ожидается.
