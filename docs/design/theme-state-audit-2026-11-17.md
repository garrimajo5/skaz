## Воспроизведение

1. Убедиться, что 127.0.0.1:4337 свободен, запустить `node scripts/theme-state-fixture.mjs`.
   Стенд не принимает путь к рабочей БД и слушает только loopback.
2. Открыть `http://127.0.0.1:4337/#play`. Использовать только вымышленную игру.
3. Ctrl+Shift+Y снимает текущий DOM в RAM, не меняя фокус. Отчёт получить по
   `http://127.0.0.1:4337/_qa/reports` до остановки. Лимит100 снимков.
4. Ctrl+Shift+2 задерживает POST изменения ресурса; нажать одну доступную ячейку.
   Снять сразу «Сохраняю…», затем после штатного тайм-аута «Без сети».
   Ctrl+Shift+3 освобождает запрос как409 без изменения БД; повторить отправку,
   если клиент уже завершил тайм-аут. Открыть меню и «Сверить очередь».
5. Переключать темы через настройки. Для keyboard focus отвести указатель с
   кнопки, Tab/Shift+Tab до неё, затем снять отчёт. Hover с внешним outline
   помечается manual, его нельзя выдать за тот же измеренный keyboard-сценарий.
6. Завершить сверкой/архивированием тестовой очереди, Ctrl+Shift+1, закрыть вкладку,
   остановить сервер. Сервер не отправляет отчёты наружу и не пишет БД на диск.

Номер снимка и режим инъекции назначает сервер: присланные sequence/mode
не могут их заменить. Регрессия сначала воспроизвела 999 вместо1; после
исправления сервер сохраняет1 и фактический conflict. Ранее собранные
снимки этих полей не присылали, их подписи этой поправкой не меняются.

Сборщик расширен controls/selected/disabled, SVG и ресурсными метками. Граница
нулевой ширины/none/hidden больше не даёт ложный pass для полей. Контуры кнопок
с подписью информационные: декоративная линия не автоматически нарушение.
SVG через use, нативные checkbox, градиенты и неоднозначные эффекты остаются manual.
Снимки1–31 сняты до добавления resourceMarks,32–40 с ним,41–43 после защиты
от нулевой границы и исправления настроек. Хеш в JSON относится к конечному
сборщику, не утверждает идентичность всех предыдущих фаз.

## Рефлексия

Результат: воспроизводимый стенд, измерения трёх тем и устранённый дефект
выбранности. Лишняя работа: несколько снимков ожидания оказались уже offline
или ещё queued; поля mode недостаточно. Предложение планировщику: испытать
автоматическую запись видимого sync-status в метаданные следующего аудита.
Польза — меньше ошибочных подписей; затраты небольшие; риск — смешать состояние
инъекции и UI, поэтому сохранять оба. Это предложение, не изменение процесса.

Затем новая запись Ловкости 19 со стороны сервера вызвала настоящий 409 при повторе. В браузере сохранился исходный черновик 16/17/18, на сервере осталось 19. Проверка относится к редактору характеристик в одном широком размере. Остальные строки общей матрицы и физическая игровая проверка остаются открыты.
