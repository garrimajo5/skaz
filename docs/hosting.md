# Требования к компьютеру и будущему серверу

Оценка на 18 октября 2026. Это инженерные ориентиры для одной небольшой партии, не результат нагрузочного тестирования и не гарантия скорости распознавания.

## Сейчас: локальная версия

- Windows, Linux или macOS, Node.js 24+ и современный браузер.
- Обычный компьютер с 4 логическими ядрами и 8 ГБ ОЗУ достаточен как стартовая конфигурация разработки. GPU не нужен.
- Свободное место: 1–2 ГБ с запасом для приложения, базы и резервных копий без аудио.
- Сервер слушает только `127.0.0.1:4173`. С другого устройства он пока недоступен. Подключение планшета по сети будет отдельным этапом с контролем доступа.
- SQLite встроен в Node; PostgreSQL и Docker для первого запуска не нужны.

## Будущий хостинг приложения

| Режим | CPU | ОЗУ | Диск | GPU |
| --- | --- | --- | --- | --- |
| Одна партия, справочник и прогресс, AI через внешний API | 2 vCPU | 4 ГБ | 40 ГБ SSD | Не нужен |
| Запас для нескольких кампаний, PostgreSQL и фоновых задач | 4 vCPU | 8 ГБ | 80 ГБ SSD | Не нужен |
| Отдельный экспериментальный узел распознавания речи | 8 vCPU | 16–32 ГБ | 100 ГБ SSD | Ориентир 12–16 ГБ VRAM |

Для первого размещения предлагается **2 vCPU / 4 ГБ / 40 ГБ SSD**, Linux, HTTPS, постоянный диск, ежедневные резервные копии вне этого сервера. Аудио и изображения лучше вынести в объектное хранилище. Перед открытием доступа потребуется авторизация и разграничение данных; текущий локальный API не предназначен для прямого размещения в интернете.

Сервер должен поддерживать долговременный процесс Node.js, постоянное хранилище и исходящие HTTPS-запросы к выбранному провайдеру AI. Для базы с PostgreSQL и очереди обработки имеет смысл сразу взять вариант 4 vCPU / 8 ГБ. Автоматическое масштабирование пока не требуется.

## Распознавание: два разных бюджета

При использовании внешнего API основная вычислительная нагрузка остаётся у провайдера. Наш сервер принимает небольшие фрагменты записи, хранит задания, получает расшифровку и предлагает изменения. Сначала стоит измерить качество на 15–30 минутах вашей игры, затем на шестичасовой сессии.

Для самостоятельного запуска распознавания потребуется отдельный процесс с моделью и обычно GPU. В официальной таблице Whisper указаны приблизительно 6 ГБ VRAM для turbo и 10 ГБ для large. Предложенные 12–16 ГБ — запас, а не обязательное требование самой модели. Скорость зависит от GPU, модели и реализации; реальные разговоры на русском, перебивания и распределение реплик по говорящим нужно тестировать отдельно. Извлечение сюжетных фактов языковой моделью — ещё одна нагрузка: её требования сюда не включены.

Источник: [Whisper — available models and languages](https://github.com/openai/whisper#available-models-and-languages).

## Размер записей

Для шести часов моноаудио арифметическая оценка при постоянном битрейте:

- 64 кбит/с: около 173 МБ;
- 96 кбит/с: около 259 МБ;
- PCM 16 кГц, 16 бит, моно: около 691 МБ.

Реальный размер зависит от формата и контейнера. Для сжатого оригинала, фрагментов и резервных копий разумно предварительно заложить до 1 ГБ на сессию. Хранение промежуточных WAV может увеличить объём. Срок хранения записей задаётся отдельно от хранения журнала.

Покупать GPU-сервер сейчас не требуется: сначала рабочее сохранение и интерфейс, затем пилот распознавания и замеры.
