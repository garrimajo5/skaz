## Повторяемая проверка локальных снимков

`node scripts/verify-catalog-al-captures.mjs <evidence-directory>` читает только локальные `jungle-preview.pdf` и `5962.html`, `5963.html`, `5965.html`, `5966.html`, `5970.html`, `5971.html`, `5977.html`, `6005.html`. Проверяет исходные байты, идентичность, источники и выбранные поля всех восьми карточек. Сеть и запись файлов не используются; недостающий или изменённый снимок вызывает ошибку. Пути не строятся из заголовков либо URL. Проверка выполнена на реальных снимках20.11.

SHA не подтверждает правильность ручной транскрипции PDF: её независимо проверяют визуально по указанным страницам. Снимки получают из законно доступных источников и хранят вне Git; повторное скачивание может дать другие байты, что требует новой сверки, а не перепривязки хеша вслепую. Отдельный тест подтверждает, что порядок ключей JSON не создаёт ложного расхождения параметров.
