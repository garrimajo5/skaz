# Краткие сведения в строках заклинаний

08.11.2026. Программные критерии #19: классификация всех 319 SRD-заклинаний,
фильтры, строки 50 px, боковая карточка и кнопки #20 реализованы и проверены.
Полнота подробных боевых сведений — отдельное ограничение данных: **16 из 319**.
Остальные 303 показывают уже известные дистанцию/концентрацию/ритуал и
предоставляют полную сохранённую карточку. Отсутствие кратких сведений не
означает отсутствие урона или спасброска у заклинания.

Сверены по включённым текстам SRD 5.1 (2014): Cure Wounds, Healing Word,
Acid Splash, Chill Touch, Fire Bolt, Ray of Frost, Poison Spray, Sacred Flame,
Vicious Mockery, Burning Hands, Magic Missile, Thunderwave, Shatter, Fireball,
Lightning Bolt, Hold Person. В модуле сохранены полный текст, версия, URL,
лицензия CC BY 4.0, атрибуция и условия изменения источника. Это не официальный
перевод и не автоматическое применение эффекта.

Данные задаются вручную в scripts/build-spell-facts.mjs; генерация повторяема.
client/spell-facts.js использует только точное совпадение ID, редакции, круга,
версии/URL источника и полного текста сохранённой карточки. При личной правке
или неизвестной версии подсказка не переносится только по названию/ID.
Список охвата и всех пропусков: catalog/spell-quick-facts.coverage.json.

Заговоры масштабируются по общему уровню персонажа 5/11/17. Для шаблона это
5-й уровень, для собственного класса — явно сохранённый общий уровень.
При неизвестном уровне выводится база. Для заклинаний с ячейками формула
помечена «база»: повышения круга, черты и другие модификаторы она не учитывает.
У лечения «+мод.» означает модификатор заклинательной характеристики, а не
фиксированное +4. Волшебная стрела показывает три отдельных дротика, а
не выдуманный единый бросок; половина при успешном спасброске сохранена.

Дальнейшее наполнение не включается автоматически в очередь «Дизайн 2.0».
Для расширения нужен отдельный согласованный объём с проверкой источников;
полнота 319 боевых формул не заявляется текущим выпуском.
