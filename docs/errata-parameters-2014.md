# SKT и DMG2014: ограниченная сверка параметров

Задача #77, роль content, 19.11.2026. Это проверяемые свидетельства и кандидаты связей, не полный каталог, не готовая автоматизация и не разрешение воспроизводить книги. Главный реестр, приложение и личные профили не изменены. `accepted=false`, знаменатель не принят; M0 закрывает владелец.

## Первичные источники

- [SKT errata v2.0](https://media.wizards.com/2020/dnd/downloads/SKT-Errata.pdf), copyright2021, 4страницы, SHA256 `7be9a8709571785f9db1bec87a921afcac11712e9f8a85009f3c1229c983c61d`.
- [DMG errata v3.0](https://media.wizards.com/2021/dnd/downloads/DMG-Errata.pdf), copyright2021, 2страницы, SHA256 `257679dba5ab5f1d6656b9bc508ad82a5a053ea49d57dbeee6e88a5fe01d6afb`.
- [Публичный индекс SKT](https://www.dndbeyond.com/monsters?filter-source=12): шесть страниц,105карточек. Это современный цифровой индекс, а не доказанный состав печатного издания.
- [Официальная HTML-эррата SKT](https://www.dndbeyond.com/sources/dnd/sae/storm-kings-thunder) и [DMG2014](https://www.dndbeyond.com/sources/dnd/sae/dungeon-masters-guide-2014) использованы с явной границей редакции. Общий URL DMG без2014 не подменяет выбранный источник.

PDF/HTML доступны аудиторам как внешние входы; полные книги и личные данные в Git не добавлены. Хеши JSON-входов нормализуют только CRLF→LF; PDF проверяется побайтово.

Пустой CR не превращается в0: общий парсер допускает его только при явном opt-in с зафиксированным смыслом. Старые Folio/IMR остаются строгими. Shield Dwarf, Storm Giant Princess и Axe of Mirabar Veteran оставлены неразрешёнными группами. Eigeron’s Spirit/Ghost — кандидат, не утверждённый алиас. Hulking Crab не получил выдуманного соответствия по одному похожему имени.

У Storvald DC/атака не напечатаны; `null` означает отсутствие в выбранном действии. Для Maegera частота не указана.10локальных исключений времени и два Fire Bolt1d10 относятся только к соответствующим действиям; базовое заклинание не изменяется. У основного действия шамана частоты указаны явно; частота племенных заклинаний в эррате не повторена. Требование священного свёртка и вторичные ограничения сохранены отдельно. Проверка прежних сравнений SKT сверяет выбранные числовые поля/компоненты/исключения, но не является полной повторной проверкой их списков и частот.

DMG: Pearl of Power восстанавливает потраченный слот4+ как3, а не запрещает выбрать его; Spell Scroll не расходуется при прерывании обычного накладывания. Проверки провала/переписывания свитка здесь не установлены. В XP-таблице источник исправления DMG101 отделён от исходных существ MM103. Игровые условия остаются справочной основой предупреждений; ручной путь и личные исключения не меняются.

## Воспроизведение

Передать локальные копии с указанными SHA (порядок HTML: страницы1–6):

```text
python scripts/audit-skt-spellcasting-actions.py <SKT.pdf>
python scripts/audit-skt-tribal-edits.py <SKT.pdf>
python scripts/audit-skt-index.py <p1.html> <p2.html> <p3.html> <p4.html> <p5.html> <p6.html>
python scripts/audit-dmg-selected-item-errata.py <DMG.pdf>
python scripts/audit-dmg-xp-table.py <DMG.pdf>
node scripts/catalog-skt-index-review.mjs <output.json>
node scripts/catalog-tribal-spell-review.mjs <output.json>
node scripts/catalog-action-spell-review.mjs <output.json>
```

Фактически: аудиторы прошли13/13действий с132упоминаниями,11явных племенных удалений и условия,105/105карточек,11/11предметов и10/10XP. Три производных отчёта воспроизводятся вместе с хешами. Полный WindowsPython190/190; LinuxUbuntuPython3.8.2 —27/27новых тестов, не полный Linux-набор; дополнительно Linux-регрессии общего парсера Folio5/5 и IMR4/4. Профильный Node30/30, check/build прошли. LinuxNode отсутствует, результат не заявляется. Негативные тесты проверяют пропуски/дубли/перестановки, пустой CR против0, неоднозначные имена, локальность исключений и неподтверждённую приёмку.

Разрешённый независимый read-only reviewer проверил пакеты и дельты без блокеров; тесты и реальные аудиторы сам не запускал. Первичные13действий/таблицаXP проверены отдельно; вторичные предметы независимо выборочно (Pearl/Scroll/Instrument), прочие страницы — автором.105HTML-строк автоматически сверены автором, не перечитаны reviewer целиком.10вторичныхXP автором проверены по страницам; reviewer их повторно не запрашивал. Это не независимое подтверждение всего каталога.

Полезным оказалось разделение напечатанного, отсутствующего и вторичного значения: оно предотвратило выдуманные CR/DC и глобальное изменение заклинаний. Лишнюю работу вызвал строгий парсер пустого CR; исправление ограничено opt-in, старые источники защищены регрессиями.
