# Длительность, концентрация и цели — #77/D05

[Отчёт](../catalog/general-concentration-targets-2014.json) сопоставляет 6 полных выбранных текстовых подразделов: 13 русских абзацев и 3 пункта списка. Primary — SRD102; общее округление проверено отдельно по Basic2018, PDF5. Использованы сохранённые источники, нового HTTP не было.

- Мгновенная магия не существует как продолжающийся эффект для рассеивания. Это не отменяет её последствий и не решает вопрос Counterspell до завершения сотворения.
- Концентрацию можно прекратить без действия. Обычные движение и атака её сами не прерывают. Другое заклинание с концентрацией завершает предыдущее; недееспособность и смерть прерывают её.
- Каждый независимый источник урона требует отдельного спасброска Телосложения, СЛ max(10, floor(damage/2)). Округление вниз имеет собственное свидетельство Basic5; оно не приписано формулировке SRD о концентрации. Лицензия SRD на Basic не переносится. Проверку от окружения с СЛ10 назначает мастер по обстоятельствам, а не любое движение автоматически.
- Тип цели задаёт заклинание. Невидимость не равна полному укрытию. При размещении невидимой точки области за препятствием сохранено правило возникновения с ближней стороны. Можно выбрать себя при разрешённой цели, кроме явных исключений. Дистанция Self у области не означает, что она затрагивает только заклинателя.

**Расхождение перевода:** русское условие «у цели нет воспринимаемого эффекта» относится к цели; primary говорит о воспринимаемом эффекте заклинания. Различие сохранено как referent mismatch. Источник молча не исправляется, осведомлённость NPC автоматически не вычисляется. Полное равенство перевода не заявляется.
