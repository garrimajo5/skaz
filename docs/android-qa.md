# Проверка Android — 08.11.2026

Проверена локальная версия СКАЗ в Chrome на запущенном эмуляторе Android Studio
Pixel_8 (emulator-5554). Управление — ADB input; изображения — screencap/pull.
Пример DeepDive использован только как подсказка метода: чужой QA-скрипт,
установка APK и изменение того репозитория не выполнялись. СКАЗ — веб-приложение.

Использована отдельная вымышленная игра на localhost:4185 через adb reverse.
Рабочие кампании не менялись. Размеры: телефон 1080×2400, density 420, обе
ориентации; затем временный размер 1600×2560, density 320, в альбомной ориентации.
Последний режим проверяет планшетную раскладку, но не эмулирует отдельное
планшетное устройство. После проверки исходные размер, плотность, автоповорот
и настройка клавиатуры восстановлены; проброс порта удалён.

## Подтверждено действиями и изображениями

- Урон 8: предварительный расчёт 24→16, применение, отмена до 24. После отмены
  повторная кнопка отмены не предлагается, цепочка «Отмена: Отмена» не появляется.
- Личная заметка: настоящая экранная клавиатура Android, поле и сохранение
  остаются доступны; после сохранения клавиатура закрывается.
- При отказе API (HTTP 503) десять чередующихся списаний/восстановлений ячейки
  первого круга попали в очередь. После перезагрузки страницы без API сохранены
  все 10 действий и баланс 1/4. После восстановления API и «Отправить очередь»
  очередь опустела, серверная история содержит все десять переходов 1→0→1
  по порядку. Это проверка отказа сервера, а не физического отключения Wi-Fi.
- Исправленная горизонтальная раскладка телефона оставляет место для страницы;
  пульт прокручивается горизонтальным жестом до заметки и концентрации,
  навигация остаётся доступной. Кнопки героя в портрете больше не стоят узкой
  высокой колонкой. Кнопка отмены не сжимается до обрезанного текста.

Локальные изображения и журналы находятся в игнорируемой data/android-qa/;
они не входят в Git. CSS не меняет цвета трёх тем. Автоматические проверки
контраста всех тем, ресурсов, очереди и общих строк: 24/24; синтаксис и сборка
успешны. Android-визуальная проверка выполнена на Полярисе.

## Что этим прогоном не подтверждено

Не выполнена полная приёмка каждого экрана и всех тем на Android. Не проверены
реальный iPad, Safari, Split View, выгрузка браузера системой, двухчасовая и
шестичасовая игровые сессии. Issues #1/#11/#12/#15 и сводка #16 остаются открытыми.
Следующая проверка — физический iPad по существующему полевому чек-листу.

## Совместное использование эмулятора — 11.11.2026

Пользователь сообщил: другой проект использует Pixel_8 ежечасно примерно
семь минут. В показанной истории старты сдвигаются от :00 до :18.
Для СКАЗ выбирать окно :25–:55 и перед началом проверять фактическую
занятость. Если чужое приложение или прогон активны, продолжать независимую
работу, не менять настройки и не закрывать чужие приложения. Завершать свои
действия и восстанавливать только собственные изменения до следующего окна.
