# Текущий остаток выбранных D04-проверок

Refs #77. [Воспроизводимый остаток](../catalog/m0-d04-residual-review-2014.json) связывает исторические диагностики с независимо проверенными reference-типами/именами, не переписывая effective-m0-review.

- Пять пустых EN-полей объяснены типами страниц-коллекций; пустые поля сохраняются, английские названия пяти самостоятельных предысторий не изобретаются.
- Из пяти алфавитных диагностик три имеют проверенный справочный label; оригиналы/aliases/sourceIds/группы остаются в исходном слое.
- Два условия открыты: точная legacy-карточка568 и первичное имя/публикация20456. Их нельзя закрыть другой версией Nilbog или транслитерацией.

Это остаток **выбранных полей D04**, а не всего M0, не процент готовности и не два единственных препятствия проекта. Полные правила, компоненты коллекций, права, версии и другие решения M0 не принимаются. Canonical/background/component units0, denominator:null; этапы и issue открыты, runtime/персонажи не меняются.

CLI `node scripts/review-m0-d04-residuals-2014.mjs` проверяет актуальность без записи, `--write` регенерирует фиксированный артефакт. Он переиспользует проверку точных reviewed page kinds и label view, проверяет исходное пустое поле/URL/sourceIds перед объяснением диагностики. Семь Node-тестов: чужие/повторные диагностики, изменённые байты, stale label view, подавление hold, source/EN-подмена, запрет полной приёмки и отсутствие мутации входов. Шесть входов закреплены SHA.

Следующий шаг — read-only ревью свода, затем два конкретных источниковых условия D04 либо другие доступные M0-пункты. Приватный source-review22заметок#78 остаётся под отдельным запросом; этот публичный свод не обходит его. Browser/Android/выпуск приложения неприменимы.

Рефлексия: старый корневой отчёт намеренно хранит первоначальные5+5диагностик; чтение его без слоёв провоцирует повтор готового. Предложение — использовать текущий остаток при следующем выборе D04, с проверкой input pins; польза меньше повторов/логов, затраты один быстрыйCLI, риск ложной полноты ограничен явной областью выбранных полей. Общие инструкции не изменены.
