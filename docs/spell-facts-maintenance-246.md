# Общая сводка заклинания — #246

## Путь и область

На main0229aa0 оба экрана уже вызывали `SkazSpellFacts.summary`: каталог без уровня помещает строку в `catalog-tile-effect`, «Игра» передаёт общий уровень и добавляет сводку к дистанции/концентрации/ритуалу. Оба экранируют результат как текст. Парсинга строки или собственной формулы у них нет; удачное переиспользование сохранено. `client/catalog.js` не изменялся.

Авторитетный код — `scripts/build-spell-facts.mjs`. Он генерирует `client/spell-facts.js`; после правки выполнить `node scripts/build-spell-facts.mjs`. Тест воспроизводимости проверяет точное совпадение результата. Новых runtime-зависимостей, ORM, языков, i18n-фреймворка, миграции клиента/SQLite нет.

## Контракт

`calculate(entry, characterLevel)` — чистая функция: сначала прежняя проверка exact ID/ruleset/kind/circle/source version/URL/text, затем числа и устойчивые коды. Результат: savingThrow/attack, damage(dice.count/sides,bonus,type,projectiles,basis), healing(dice,addSpellcastingModifier,basis), onSuccessfulSave.damageMultiplier, effect. Нет HTML, русских подписей, применения урона/списания ресурса или изменений карточки. Вложенные объекты создаются заново.

`format(facts)` — общий русский вывод. Здесь сокращения характеристик, типы урона, effect, «спас», «лечение», «(база)», «успех: ½», символ кости и разделитель. `summary(entry,level) = format(calculate(entry,level))` остаётся общей точкой входа. Условия половины урона представлены числом0.5, не готовой подписью.

Проверка карточки не заменена поиском по имени/ID. Включён собственный ключ records, чтобы prototype-like ID не принимался за запись. Несовпадение возвращаетnull; каталог скрывает только effect-строку, «Игра» сохраняет обычные метаданные/чтение/действия. Личная карточка с тем жеID и изменённым текстом остаётся доступной без чужой checked-сводки.

## Одна цепочка

Реальная bundled-карточка `srd51:2014:spell:acid-splash` + общий уровень5:

```js
calculate(entry, 5)
// savingThrow: 'dex'
// damage: {dice: {count: 2, sides: 6}, bonus: 0,
//          type: 'acid', projectiles: null, basis: 'character-level'}
// healing: null, onSuccessfulSave: null, effect: null, attack: null
format(facts)
// 'спас ЛОВ · 2к6 кислота'
summary(entry, 5)
// та же строка для любого экрана
```

«Игра» передаёт5 и отображает `60 фт · спас ЛОВ · 2к6 кислота`. Каталог не задаёт уровень персонажа, поэтому намеренно показывает `спас ЛОВ · 1к6 кислота (база)`. Если обоим передать одинаковый уровень, формула и строка одинаковы; потребители не рассчитывают/не переводят эти факты.

Формула текущих заговоров1/5/11/17 меняется **только в cantripDiceCount** генератора. Подпись/сокращение меняется **только в format/ru** того же файла. После изменения регенерировать и проверить числовые facts отдельно от ожидаемой строки и реальных renderer-тестов.
