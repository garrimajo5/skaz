Следующий шаг — отдельные первичные свидетельства исходной эпохи/прав: публичные превью Grung и Locathah доступны, Tortle-превью403 и не обходится. После независимой проверки — геймдизайнерский вывод по согласованному WotC2014-объёму, без подмены прав доступностью.

Лишняя работа: начальный поиск пытался повторно доказать уже имеющуюся библиографию; сопоставление исходных полей выявило настоящий дефект numeric-only диагностики. Предложение — сначала проверять sourceTitle+bibliographyEvidenceId, затем искать новый источник; польза меньше повторных сетевых запросов, затраты один адаптер и10тестов, риск нечёткой привязки снят точной парой ID/названия. Общие инструкции не изменены.
