# Предложение границ классовых единиц — #77/M0

Роль: геймдизайнер, авторское предложение по существующим критериям #77 (состав/единица/версия/дубли/знаменатель). [Воспроизводимый JSON](../catalog/class-unit-granularity-proposal-2014.json) использует существующую Wizard/Artificer матрицу и проверенную таблицу. Это не независимая приёмка собственных source-аудитов и не изменение границ MVP.

| Наблюдения выбранных двух классов | Предлагаемая роль | Количество наблюдений |
| --- | --- | --- |
| Base feature | Кандидат самостоятельного классового умения |21|
| Subclass | Родитель выбора подкласса |17|
| Subclass feature | Кандидат умения выбранного подкласса |90|
| Rules guidance | Справочная вставка с сохранением родителя |2|

Итого130 исходных наблюдений, **не130 принятых единиц каталога**. Сохранены порядок ID, sourceIds/sourceBasis/URL, родитель и observedInitialLevels. Отдельные23Artificer headings остаются таблицами/компонентами/контейнерами/справкой, а не23новыми способностями. Все canonicalId=null; глобальный denominator не установлен. Соответствие observation→canonical не фиксируется как1:1: версия может требовать разделения, а общий reference-view допустим без потери исходных наблюдений.

Игровые примеры предложения:

- ASI: один исходный Wizard-ID и class-level occurrences4/8/12/16/19; выбор/история события отдельны от личности каталожной записи. Импортированное улучшение не применяется снова.
- Spellcasting: один feature-observation с адресуемыми компонентами, а не21способность по абзацам/подписям inventory.
- Подкласс: каталог показывает варианты, но его наличие не выдаёт персонажу все13Wizard подклассов/детей.
- Две вставки «Дюнамантия для не дюнамантов» (headings96/102) имеют одинаковые полные secondary bodies (по2абзаца). Предложен общий reference-view, **оба parent-specific ID/source116 сохраняются**. Это не canonical alias, не доказательство равенства primary EGW и не новое автоматическое умение.
- Игровое исключение допускает ручное сохранение с предупреждением; необязательный GM-флажок не становится условием действия. Эти примеры — проектное решение, не проверка реализованного экрана.

Фактический `server/catalog.mjs` принимает kind mechanic/spell/monster/item/artifact. Предлагаемые роли представления не объявляются новыми runtime-kind и не являются импортируемым bundle. Для будущего классового API/схемы понадобится отдельное продуктовое изменение; этот пакет не вводит миграцию и не редактирует профиль.

```sh
python scripts/review-class-unit-granularity-2014.py --class-html <class-105.html> --output <report.json>
python -m unittest discover -s tests -p test_class_unit_granularity_2014.py
```

11 Python проверок сохраняют130/23/parents/source/order/levels, отсутствие mutable alias исходных массивов, ASI occurrences, scoped guidance witnesses и отделение предложения от runtime/denominator. Свидетельство одинаковой справки закреплено SHA полного сохранённого Wizard HTML; исходная HTTP-квитанция недоступна, статус/время не придуманы. Нового HTTP нет.

Проверка полного текста каждого высокоуровневого умения не добавляется как новый входной барьер M0 этим предложением.
