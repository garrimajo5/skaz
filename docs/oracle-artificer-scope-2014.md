# Изобретатель в Oracle of War v1.5

27.11.2026. [Реестр #77](https://github.com/garrimajo5/skaz/issues/77) · [контракт мультикласса #82](https://github.com/garrimajo5/skaz/issues/82). В [отчёте сверки](../catalog/oracle-artificer-scope-2014.json) сохранены размеры PDF, SHA-256 и отпечатки трёх фрагментов.

Сверены две официальные публикации Wizards of the Coast. В PDF Player’s Guide применяется FAQ на странице 8, в DM’s Guide — FAQ на странице 5. Во всех трёх выбранных ответах нормализованный текст совпадает. Страницы проверены визуально. [Player’s Guide](https://media.wizards.com/2021/dnd/downloads/OracleofWar_PGv1_5.pdf#page=8) · [DM’s Guide](https://media.wizards.com/2021/dnd/downloads/OracleofWar_DMGv1_5.pdf#page=5)

| Область кампании | Что подтверждено |
| --- | --- |
| Версия класса | Oracle of War использует Изобретателя из Tasha’s Cauldron of Everything, источник 117. Руководство указывает на эррату Eberron: Rising from the Last War, источник 119, для обновления предыдущей публикации. |
| Инфузии | В этой кампании инфузии исключены из лимита владения магическими предметами. Обычно они заканчиваются по завершении приключения. При нескольких последовательных приключениях с теми же персонажами и тем же мастером мастер может разрешить сохранить их между играми. |
| Wayfinder | Для Oracle of War допустим совпадающий с Eberron текст. Эквивалентность отдельных правил устанавливается сравнением конкретных версий. |

Кампанийный FAQ не определяет округление общего уровня заклинателя. Для расчёта #82 ещё нужны соответствующий абзац опубликованного класса и сверка конкретного подкласса. Указание о версии кампании не меняет обычный срок инфузии и не запускает сброс предметов. Совпадение трёх ответов в двух руководствах даёт три свидетельства.

На обеих страницах разрешены печать и копирование для личного использования. Файлы и текст ответов остаются вне репозитория. Реестр пока содержит указатели и факты. Для публикации текста или перевода нужны отдельные основания.

## Воспроизведение

Скачать два PDF [средством захвата](../scripts/capture-publication-witnesses.py). В плане указываются два адреса из отчёта без фрагмента страницы и имена `oracle-player-guide.pdf` и `oracle-dm-guide.pdf`. Каталог снимков находится вне репозитория.

```sh
python scripts/audit-oracle-artificer-scope-2014.py <capture-directory> --output <report.json>
python -m unittest discover -s tests -p test_oracle_artificer_scope_2014.py
```

Сверка проверяет статус выдачи, оба адреса, SHA и границы FAQ. Извлекатель отдаёт нижнюю пометку до заголовков. Поэтому граница ответа о версии в Player’s Guide доходит до конца извлечённой страницы, а в DM’s Guide останавливается перед вопросом о ремесле. Данные каталога, расчёты и выпуск СКАЗ сохраняют прежнее состояние.
