# Исправление строки справочника — 15.11.2026

Владелец показал `https://2.56.179.225/#library`: названия/арты сдвинуты
вправо, у восьми из девяти показанных заклинаний вместо арта значок школы.

Причина раскладки: `.catalog-row>button { grid-column:3 }` от прежней
кнопки «Читать» применяется к новой кнопке, содержащей всю строку.
У родителя две колонки; браузер создаёт третью, оставляя первую пустой.
Добавлено более специфичное правило `.entry-row>.entry-primary` с
`grid-column:1/-1; grid-row:auto; min-width:0`. Инвентарные строки с
details и отдельными действиями не меняются.

Воспроизведение без данных игры: `node scripts/catalog-row-review.mjs`.
Стенд слушает случайный свободный loopback-порт и использует настоящие
SkazUI.entryRow, CSS, SkazArt и createArtLibrary, девять заклинаний со
скриншота. Сервер не подключает пользовательскую БД. Порт 4337 не используется.

Браузер до: при ширине1280 начало первой кнопки x=965.7 внутри строки x=8,
grid-column=3. После: x=17 для всех девяти, grid-column=1/-1, без overflow;
9/9 изображений загружены. Проверены Полярис1280×720, Атлас390×844,
Уголь820×1180. Это локальная проверка реальных компонентов, не вход на VPS
через браузер: встроенный браузер не имеет Basic-аутентификации сайта.

SSH read-only подтвердил текущий VPS `/opt/skaz/releases/b2fa33a`.
Его Git-манифест содержит290 артов. Из показанных заклинаний только
conjure-animals есть в этом выпуске. confusion, conjure-celestial,
conjure-elemental, conjure-fey, conjure-minor-elementals,
conjure-woodland-beings, contact-other-plane, contagion уже имеют принятые
арты в main. Поэтому требуется выпуск существующих580 артов, а не генерация.

Согласовано новое действующее правило: доводить изменения до VPS в той же
сессии после проверок. Указание записано в начале DEVELOPMENT_PLAN.md и
deployment.md. Фактический новый выпуск и резерв фиксируются отдельно после
Linux-проверок, репетиции восстановления и переключения. Android не использован.
