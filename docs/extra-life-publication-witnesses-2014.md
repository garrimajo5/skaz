# Проверяемые библиографические PDF-свидетельства

Refs #77 D01/D05/D07;content. Этот пакет закрепляет существующие утверждения об эпохе первичными байтами/областями, а не объявляет годы публикаций новым открытием. Named-race-source-policy уже содержал2017/2019; исходная библиография и политика не меняются.

[Контракт](../catalog/extra-life-publication-witnesses-2014.json), [воспроизводимый аудит](../catalog/extra-life-publication-witness-audit-2014.json): три публичных издательских PDF-превью, пять областей/девять якорей. Grung-превью2страницы, Locathah6, Kwalish6. Четыре страницы просмотрены визуально: Grung2, Locathah1/2, Kwalish1. Авторская визуальная проверка не считается независимой.

- [Grung](https://d1vzi28wh99zvq.cloudfront.net/pdf_previews/223738-sample.pdf):2017 в выходных данных; доступен лишь титул/введение, не полные расовые правила.
- [Locathah](https://d1vzi28wh99zvq.cloudfront.net/pdf_previews/289261-sample.pdf):2019 в юридическом блоке, контекст пятой редакции, упоминание варианта персонажа. Отсылка к приложению не означает чтение самого приложения. Уведомление требует отдельного разрешения; разрешение проекта здесь не установлено.
- [Kwalish](https://d1vzi28wh99zvq.cloudfront.net/pdf_previews/258047-sample.pdf): записка команды исторически относит One Grung Above/The Tortle Package к проектам2017. Это не дата конкретной печати или подтверждение полного текста обоих продуктов.

Состояние прав text/translation:not-established. CC-положение по конкретному SRD не распространяется автоматически на остальные книги. Отсутствие установленного разрешения не объявляется выводом о незаконности. Публичная доступность превью не равна праву переиздать перевод или правила. Официальность издателя, статус правил, AL-допуск, идентичность текста и права различаются; Grung по прежней политике всё ещё ожидает проверки официального статуса правил. Его маршрут не меняется.

Tortle-превью вернуло403, обхода и неофициальных полных копий нет. Первичная цифровая41-ссылка через веб-инструмент ведёт в магазин, прямой HTTP завершился тайм-аутом; разные каналы не смешиваются. Нового полного Tortle-текста не прочитано.

## Классификация в текущем D&D Beyond

[Индекс видов](https://www.dndbeyond.com/species) содержит игровую карточку Grung из One Grung Above, цифровой ID 302384. В HTML она помечена `legacynoncore`, как карточки Locathah из Locathah Rising и Tortle из The Tortle Package. Отдельная карточка Tortle из MotM помечена `5e-expanded-rules`. [Changelog издателя](https://www.dndbeyond.com/changelog) приводит One Grung Above как пример дополнительного материала в переключателе Legacy.

[Реестр D01](../catalog/d01-extra-life-source-categories-2014.json) связывает четыре цифровых URL и исходные наблюдения. Два снимка HTML закреплены по SHA-256 и размеру. Для повторной сверки открыть карточку каждого источника в индексе, проверить класс категории в HTML и сопоставить с разделом Updates to Sources and Book Categorization. Веб-проверка ссылки Grung ведёт в магазин, отдельный прямой запрос вернул его адрес и HTTP 200, затем завершился тайм-аутом при получении страницы.

Это свидетельство о принадлежности к переключателю D&D Beyond. Один и тот же переключатель объединяет записи с разными решениями в СКАЗ. Статус официальных правил Grung в рамке каталога, соответствие полного текста и права остаются открытыми. Эффективный маршрут для Locathah и двух Tortle остаётся проверкой версий и прав.

## Допуск в Adventurers League

На первой странице раздел *What Rulebooks Should I Use?* включает Locathah Rising в список цифровых публикаций и Monsters of the Multiverse в основной список. Для переизданного правила руководство требует последнюю печать и ссылается на дополнительные источники кампании и FAQ.

Отсутствие The Tortle Package в списке на с. 1 само по себе не доказывает запрет. Правило о последней печати относится к организованной игре. Связь и различия двух версий Tortle ещё нужно подтвердить по их текстам. Недопуск Grung в Adventurers League оставляет открытым его статус для общего справочника СКАЗ. Личные решения мастера по-прежнему допустимы.

Для повторной сверки скачайте PDF по ссылке выше и сравните размер 387 932 байта и SHA-256 `4864559244bcde129d14787c99537d5990a84edf2153d3ce6b7bd4c62c1c64e2`. В пятистраничном PDF дата, правило последней печати и оба названных источника проверены на с. 1 через PDFium и по изображению. Три карточки магазина прочитаны через веб-инструмент. Прямые загрузки HTML завершились тайм-аутом с неполным телом, поэтому у страниц магазина сохранены URL и локаторы. [Структурированные данные](../catalog/d01-extra-life-source-categories-2014.json).

## Публичные сводки Locathah и двух Tortle

В открытом индексе D&D Beyond каждая сводка связана с точным адресом
карточки и названием издания. Различительные поля из блока свойств
показаны отдельно от опубликованных правил.
[Список издателя](https://www.dndbeyond.com/species).

| Наблюдение | Карточка издателя | Поля публичной сводки |
| --- | --- | --- |
| Locathah 178 | [229754 · Locathah Rising](https://www.dndbeyond.com/species/229754-locathah) | +2 Сила, +1 Ловкость, Limited Amphibiousness |
| Tortle 184 | [41 · The Tortle Package](https://www.dndbeyond.com/species/41-tortle) | +2 Сила, +1 Мудрость, Survival Instinct |
| Tortle 309 | [1026404 · Monsters of the Multiverse](https://www.dndbeyond.com/species/1026404-tortle) | Nature’s Intuition. Увеличения характеристик в этой сводке не перечислены. |

У двух Tortle четыре совпадающих заголовка. Имена и публикации различаются
для Survival Instinct и Nature’s Intuition. Для переноса и обзора сохраняются
две ссылки и два наблюдения. По совпавшим заголовкам нельзя применять одну
версию правила к обеим записям. У MotM отсутствие числа в сводке хранится
как неизвестное значение. Полный список свойств, значения действий,
соответствие текстам dnd.su и права остаются на следующем шаге.

Для воспроизведения используйте сохранённый HTML индекса по SHA-256 и
размеру из [реестра](../catalog/d01-extra-life-source-categories-2014.json).
У каждого точного href проверены единственность карточки, исходное издание
и её собственный .characters-statblock. В документе хранятся только
отличительные метаданные. Исходный HTML и иллюстрации остаются вне Git.

## Проверки

CLI `audit-extra-life-publication-witnesses-2014.py --directory <PDF-снимки>` читает локальные три строго определённые файла/URL, проверяет SHA до PDF-парсера, число страниц, выбранную область и якоря. Переиспользуется audit-selected-rule-witnesses.py. Вывод через output создаётся только в новом файле и не перезаписывает источник/старый отчёт. PDFium выбран из-за CFF: pypdf давал испорченные/повторные символы, pdfplumber терял футер; PDFium и визуальная отрисовка согласованы. Poppler предупреждал о двух шрифтах; выбранные сведения на PNG читаемы.

Восемь новых Python-тестов проверяют границы, SHA/страницы, подмену эпохи/публикации, чужую область, отсутствие полного правила и невозможность наследовать права всех книг из SRD. Реальные триPDF точно воспроизводят отчёт; три входных SHA закреплены. accepted/complete:false,denominator:null,fullCharacterRulesVerified:false. Runtime/профили/production не меняются; выпуск приложения/browser/Android неприменимы.

## Передача и рефлексия

После независимого ревью — статус правил Grung при доступном первичном свидетельстве, полные версии/права всех трёх. Не повторять годы/издателя как новую работу. Доступный резерв #77 D04 — типы пяти страниц адаптаций.

Лишняя работа: смена PDF-парсера потребовалась из-за CFF, а не отсутствия текста. Предложение — для нового шрифта проверять один футер на PNG до большой обработки; польза предотвращает ложное отсутствие/дубли, затраты одна страница, риск низок. Использование штатного инструмента вместо установки пакета сохранило окружение. Общие инструкции не переписываются.
