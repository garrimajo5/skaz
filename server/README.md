# Серверное приложение — следующий этап

В этой версии сервер предметной области ещё не реализован. `scripts/dev.mjs` — только сервер статических файлов для локальной проверки интерфейса.

Будущий сервер хранит пользователей, кампании и членство, персонажей, сессии, задания, известные места, инвентарь и каталог правил D&D 5e 2014. Аудио и карты хранятся отдельно от структурированных данных.

Извлечённое из речи событие сначала сохраняется как предложение с источником и временной меткой. Подтверждённые изменения персонажа применяются атомарно, с защитой от повторного применения и возможностью отмены. Личные заметки, общие знания и материалы мастера имеют отдельные права доступа.

Полная архитектурная гипотеза находится в [концепте продукта](../docs/product-concept.md). Выбор серверного стека и реализация API — отдельный следующий этап.
