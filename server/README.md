# Локальный сервер 0.2

Реализованы HTTP API, постоянное хранение SQLite, валидация состояния, защита от конфликтов версий, идемпотентная запись, история изменений и резервное копирование. Запуск: `node server/index.mjs` или `node scripts/dev.mjs`. Node.js 24+. По умолчанию `127.0.0.1:4173`, база `data/skaz.sqlite`; настройки `PORT` и `SKAZ_DB`.

Сейчас хранится один агрегат прогресса: ресурсы персонажа, профиль кампании, журнал, этапы заданий и заметки карты. Для многопользовательской версии предстоит выделить отдельные сущности пользователей, кампаний и сессий, серверные игровые команды и каталог правил. Аудио не записывается и не обрабатывается.

Текущий сервер предназначен для локального использования одним владельцем. Проверки Host/Origin не заменяют авторизацию. Не открывай этот порт в интернет. Личные, общие и мастерские права — следующий этап.

Контракт и ограничения описаны в [локальном API](../docs/local-api.md), требования к размещению — в [hosting.md](../docs/hosting.md).
